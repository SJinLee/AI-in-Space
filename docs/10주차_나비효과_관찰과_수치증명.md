## 📖 1. 이론 설명

### 1-1. 나비효과란? 🦋
"브라질의 나비 한 마리가 날개짓을 하면 텍사스에 토네이도가 일어날 수 있다." — 카오스 이론의 아버지 에드워드 로렌츠의 말입니다.

작은 차이가 시간이 지나면서 **어마어마하게 큰 차이**로 자라난다는 뜻이죠. 오늘 우리는 이걸 AI 인공지능에서 직접 목격합니다.

> 💡 **핵심:** "AI는 일차함수 $y = ax$ 의 곱셈 릴레이일 뿐이다." 1층의 아주 작은 오차가 10층까지 곱해지면 얼마나 커질까요?

### 1-2. 수학적 모델: 10층짜리 곱셈 릴레이

AI 모델이 입력 $x$ 를 받아서 10번 곱셈을 반복한다고 가정합시다.

$$x \xrightarrow{\times a_1} x_1 \xrightarrow{\times a_2} x_2 \xrightarrow{\times a_3} \cdots \xrightarrow{\times a_{10}} x_{10}$$

모든 $a_i = 2$ 라고 하면:
$$x_{10} = x \times 2^{10} = 1024 \cdot x$$

만약 **1층에서 방사선을 맞아** 오차 $\epsilon$ 이 생겼다면?
$$(x + \epsilon) \times 2^{10} = 1024 x + 1024 \epsilon$$

**처음 오차 $\epsilon = 0.1$ 이었는데, 10층에서는 $1024 \times 0.1 = 102.4$ 로 부풀어버립니다!** 😱

### 1-3. 지수 법칙으로 이해하기 (중2 수학)

중학교 2학년 교과에서 배운 **지수 법칙**:
$$a^m \times a^n = a^{m+n}, \quad (a^m)^n = a^{m \cdot n}$$

10층 모델에서 1층의 오차가 $n$ 층까지 도달했을 때:
$$\text{오차}_n = \text{오차}_1 \times a^{n-1}$$

즉, 층 수가 1씩 늘어날 때마다 오차는 **$a$ 배씩 곱해진다**는 말입니다. 이게 바로 **지수적 증가(exponential growth)** 입니다.

### 1-4. 층별 오차가 어떻게 자라나는지 표로 미리보기

$a = 2$ 이고 초기 오차 $\epsilon = 0.1$ 인 경우:

| 층 | 정상값 ($x_n$) | 에러값 | 오차 크기 | 배율 |
|---|---|---|---|---|
| 0 (시작) | 1.0 | 1.1 | 0.1 | $\times 1$ |
| 1 | 2.0 | 2.2 | 0.2 | $\times 2$ |
| 2 | 4.0 | 4.4 | 0.4 | $\times 4$ |
| 3 | 8.0 | 8.8 | 0.8 | $\times 8$ |
| 5 | 32.0 | 35.2 | 3.2 | $\times 32$ |
| 10 | 1024.0 | 1126.4 | **102.4** | $\times 1024$ |

> ⚠️ **충격!** 처음에는 **0.1**이라는 아주 작은 오차였는데, 10층에서는 **102.4**로 **1024배**가 되었습니다!

## 💻 2. 실습

### 실습 2-1: 1차원 오차 증폭 — 한 줄씩 찍어보기 (⭐ 이 수업의 핵심!)
```python
# 🟢 [실습 2-1] 1층부터 10층까지 오차가 자라는 모습 한 줄씩 찍기
import torch

x_normal = 1.0    # 정상적인 입력값
x_error  = 1.1    # 1층에서 방사선 맞아 0.1 오차 생김
a = 2.0           # 각 층의 곱셈 계수 (기울기)

print(f"{'층':>3} | {'정상값':>10} | {'에러값':>10} | {'오차':>10} | {'몇 배?':>10}")
print("-" * 55)
print(f"{0:>3} | {x_normal:>10.2f} | {x_error:>10.2f} | "
      f"{abs(x_error - x_normal):>10.4f} | {'시작':>10}")

for floor in range(1, 11):
    x_normal *= a
    x_error  *= a
    diff = abs(x_error - x_normal)
    ratio = diff / 0.1   # 처음 오차 대비 몇 배?
    print(f"{floor:>3} | {x_normal:>10.2f} | {x_error:>10.2f} | "
          f"{diff:>10.4f} | {ratio:>9.1f}배")

# ⭐ 출력을 잘 보세요! 층이 올라갈수록 마지막 열(배율)이 2배씩 뜁니다!
```

### 실습 2-2: 지수 법칙으로 직접 검증
```python
# 🟢 [실습 2-2] 공식이 진짜 맞는지 확인하기
import torch

a = 2.0
initial_error = 0.1

print("층 | 실측 오차 | 공식 예측 (ε × a^n) | 일치?")
print("-" * 55)

x_n = 1.0
x_e = 1.1
for n in range(1, 11):
    x_n *= a
    x_e *= a
    measured = abs(x_e - x_n)
    predicted = initial_error * (a ** n)
    ok = "⭕" if abs(measured - predicted) < 1e-9 else "❌"
    print(f"{n:>2} | {measured:>9.4f} | {predicted:>19.4f} | {ok}")

# 이 실습이 증명합니다: 오차_n = 오차_1 × a^n
```

### 실습 2-3: 곱셈 계수(a) 바꿔가며 비교
```python
# 🟢 [실습 2-3] a = 0.5, 1, 1.5, 2, 3 일 때 10층 오차 비교
import torch

initial_error = 0.1
n_layers = 10

print(f"a값  | 10층 오차                   | 배율")
print("-" * 55)
for a in [0.5, 1.0, 1.2, 1.5, 2.0, 3.0]:
    final_error = initial_error * (a ** n_layers)
    ratio = a ** n_layers
    bar = "█" * min(int(ratio / 10), 40)
    print(f"{a:>4.1f} | {final_error:>12.4f}  {bar}")

# 💡 a < 1 이면? (예: 0.5) 오차가 오히려 줄어들어요!
# 💡 a > 1 이면? 오차가 폭발적으로 커집니다.
# 💡 a = 1 이면? 오차가 그대로.
```

### 실습 2-4: 실제 PyTorch 텐서에서 재현 (AI 모델 흉내)
```python
# 🟢 [실습 2-4] 다차원 텐서로 확장해서 AI 모델과 유사하게 실험
import torch
torch.manual_seed(0)

# 10층짜리 모델 (각 층이 2배 곱하는 단순 모델)
x_clean = torch.ones(5)               # 깨끗한 입력
x_dirty = x_clean.clone()
x_dirty[0] += 0.1                     # 1번 원소만 0.1 오차

print(f"시작: 정상 = {x_clean.tolist()}")
print(f"     에러 = {x_dirty.tolist()}")
print(f"     오차 = {(x_dirty - x_clean).tolist()}\n")

for floor in range(1, 11):
    x_clean = x_clean * 2
    x_dirty = x_dirty * 2
    err = (x_dirty - x_clean).abs().max().item()
    print(f"{floor:>2}층 후 최대 오차: {err:>10.4f}")
```

### 실습 2-5: 그래프로 나비효과 시각화 📊
```python
# 🟢 [실습 2-5] 층 vs 오차 그래프 그리기
import matplotlib.pyplot as plt

initial_error = 0.1
n_layers = 10

fig, axes = plt.subplots(1, 2, figsize=(13, 5))

# 왼쪽: 일반 스케일
for a in [0.8, 1.0, 1.5, 2.0, 2.5]:
    errors = [initial_error * (a ** n) for n in range(n_layers + 1)]
    axes[0].plot(range(n_layers + 1), errors, marker='o', label=f"a = {a}")
axes[0].set_title('Butterfly Effect (linear scale)')
axes[0].set_xlabel('Layer')
axes[0].set_ylabel('Error size')
axes[0].legend()
axes[0].grid(True)

# 오른쪽: 로그 스케일 (지수 증가를 직선으로!)
for a in [0.8, 1.0, 1.5, 2.0, 2.5]:
    errors = [initial_error * (a ** n) for n in range(n_layers + 1)]
    axes[1].plot(range(n_layers + 1), errors, marker='o', label=f"a = {a}")
axes[1].set_yscale('log')
axes[1].set_title('Butterfly Effect (log scale) — exponentials become lines!')
axes[1].set_xlabel('Layer')
axes[1].set_ylabel('Error size (log)')
axes[1].legend()
axes[1].grid(True)

plt.tight_layout()
plt.show()

# 🎯 로그 그래프에서 직선이 되는 것이 바로 '지수 증가'의 증거!
```

### 실습 2-6: 진짜 PyTorch 모델에서 나비효과 재현
```python
# 🟢 [실습 2-6] 실제 Linear 층 10개 짜리 모델 통과시키기
import torch
import torch.nn as nn

torch.manual_seed(42)

# 10개의 Linear 층 (각 층 1→1 뉴런, 가중치 평균 1.3 쯤)
layers = nn.ModuleList([nn.Linear(1, 1, bias=False) for _ in range(10)])
for layer in layers:
    nn.init.constant_(layer.weight, 1.3)   # 모든 층 기울기 = 1.3

x_clean = torch.tensor([[1.0]])
x_noisy = torch.tensor([[1.0 + 0.1]])     # 입력에 0.1 오차 주입

print(f"{'층':>3} | {'정상 출력':>12} | {'에러 출력':>12} | {'오차':>10}")
print("-" * 50)

for i, layer in enumerate(layers, start=1):
    x_clean = layer(x_clean)
    x_noisy = layer(x_noisy)
    err = (x_noisy - x_clean).abs().item()
    print(f"{i:>3} | {x_clean.item():>12.4f} | "
          f"{x_noisy.item():>12.4f} | {err:>10.4f}")

# ⭐ 층이 깊어질수록 오차가 1.3 배씩 커지는 걸 확인하세요!
# 이게 바로 딥러닝의 '깊은 신경망(deep network)'이 위험한 이유입니다.
```

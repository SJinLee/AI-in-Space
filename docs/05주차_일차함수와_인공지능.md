## 📖 1. 이론 설명

### 1-1. 일차함수 복습: $y = ax + b$
중2 수학에서 배운 일차함수입니다. $x$가 정해지면 $y$가 자동으로 계산되는 **식**이죠.

| 기호 | 이름 | 역할 |
|------|------|------|
| $a$ | 기울기 (slope) | 직선이 얼마나 가파른지 |
| $b$ | $y$절편 (intercept) | 직선이 $y$축과 만나는 점 |
| $x$ | 입력 (input) | 우리가 넣는 값 |
| $y$ | 출력 (output) | 식이 뱉어내는 값 |

**예시:** $y = 2x + 3$에 $x = 5$를 넣으면? $y = 2 \times 5 + 3 = 13$

> 💡 **핵심:** 일차함수는 "$x$라는 숫자를 넣으면 $y$라는 숫자가 나오는 계산 상자"입니다.

### 1-2. 인공지능은 일차함수의 거대한 묶음!
놀라운 사실 하나. **딥러닝(Deep Learning)** 이라 불리는 최첨단 AI도 속을 뜯어보면 $y = ax + b$ 수백만 개가 모인 덩어리일 뿐입니다.

AI 세계에서는 이름이 조금 다르게 불립니다.

| 수학 기호 | 수학 이름 | AI 이름 | AI 약자 |
|-----------|-----------|---------|---------|
| $a$ | 기울기 | **가중치** (Weight) | $w$ |
| $b$ | $y$절편 | **편향** (Bias) | $b$ |

즉 AI 식은 이렇게 생겼습니다:
$$y = wx + b$$

모양은 똑같은데 이름만 바뀌었습니다!

### 1-3. AI 학습 = 가장 좋은 $w, b$ 찾기 스무고개
**스무고개 게임**을 떠올려봅시다. 친구가 마음속에 숫자를 정했고, 나는 "그 숫자보다 크니?"라고 물으며 조금씩 정답에 다가갑니다.

AI도 똑같습니다. 주어진 데이터에 **가장 잘 맞는** $w$와 $b$를 찾는 게 학습입니다.

**예시 상황:** 키 $x$와 몸무게 $y$의 데이터가 있다고 합시다.

| 키 $x$ (cm) | 몸무게 $y$ (kg) |
|-------------|------------------|
| 150 | 45 |
| 160 | 52 |
| 170 | 60 |

이 점들을 가장 잘 지나가는 직선 $y = wx + b$를 찾는 게 AI의 일입니다.

### 1-4. 오차(Error): 얼마나 틀렸는지 재는 자
어떤 $w$가 더 좋은 $w$인지 어떻게 판단할까요? 바로 **오차(Error)** 로 판단합니다.

$$\text{오차} = (\text{실제값} - \text{예측값})^2$$

제곱하는 이유는? 오차가 음수이든 양수이든 모두 "나쁨"으로 세기 위해서입니다.

**예시:** 실제값 60, 예측값 58이면 오차 = $(60 - 58)^2 = 4$

모든 데이터의 오차를 더하면 **총 오차**. 이 총 오차가 가장 작은 $w, b$를 찾는 게 목표!

> 💡 **핵심:** AI 학습 = $w$를 조금씩 바꿔가며 오차를 줄이는 스무고개

### 1-5. 우주 방사선과 가중치
AI가 수많은 데이터로 겨우 겨우 찾아낸 소중한 $w$ 값. 그런데 **우주 방사선**이 이 $w$의 비트를 뒤집어 버리면?

| 상황 | $w$ 값 | 예측 $y = wx + b$ (x=170, b=0) |
|------|--------|----------------------------------|
| 정상 | 0.35 | 59.5 kg (거의 정답!) |
| 방사선 맞음 | -1.25 | -212.5 kg (???) |

> ⚠️ 비트 하나 뒤집혔을 뿐인데 예측이 말도 안 되는 값으로! 이게 우리가 앞으로 증명할 **나비효과**입니다.

### 실습 2-1: 일차함수 계산기 만들기
```python
# 🟢 [실습 2-1] 일차함수 y = ax + b 파이썬 함수로
def linear(x, a, b):
    """일차함수 y = ax + b 를 계산"""
    y = a * x + b
    return y

# y = 2x + 3 계산해보기
print(f"x=1 → y = {linear(1, 2, 3)}")   # 5
print(f"x=5 → y = {linear(5, 2, 3)}")   # 13
print(f"x=10 → y = {linear(10, 2, 3)}") # 23

# AI식으로 이름만 바꾸면
def ai_neuron(x, w, b):
    """AI의 뉴런: y = wx + b (이름만 바뀜!)"""
    return w * x + b

print(f"AI뉴런(5, 2, 3) = {ai_neuron(5, 2, 3)}")  # 똑같이 13
```

### 실습 2-3: 데이터에 맞는 직선 찾기 (손으로 스무고개)
```python
# 🟢 [실습 2-3] 키-몸무게 데이터에 맞는 w를 스무고개로 찾기
import numpy as np

# 데이터: (키, 몸무게)
x_data = np.array([150, 160, 170, 180])
y_data = np.array([45,  52,  60,  68])

# 여러 w 값을 시도해보자 (b는 편의상 0으로 둠, x는 키-150으로 밀어서 생각)
# y = w * (x - 150) + 45 라는 간단 버전
def total_error(w, b):
    predictions = w * (x_data - 150) + b
    errors = (y_data - predictions) ** 2
    return errors.sum()

# 여러 후보 w 값을 시험해보기!
print("w 값 스무고개 시작!")
print("-" * 40)
for w_try in [0.5, 0.6, 0.7, 0.75, 0.77, 0.8, 0.9, 1.0]:
    err = total_error(w_try, 45)
    print(f"  w = {w_try:>4} → 총 오차 = {err:>7.3f}")

print()
print("가장 오차가 작은 w가 '정답'에 가까운 가중치!")
```

### 실습 2-4: 오차 그래프로 "골짜기" 시각화
```python
# 🟢 [실습 2-4] w를 바꿔가며 오차 그래프 그리기 - 골짜기 모양!
import numpy as np
import matplotlib.pyplot as plt

x_data = np.array([150, 160, 170, 180])
y_data = np.array([45,  52,  60,  68])

# w를 0부터 2까지 촘촘하게 시험
w_list = np.linspace(0, 2, 200)
error_list = []

for w in w_list:
    pred = w * (x_data - 150) + 45
    err = ((y_data - pred) ** 2).sum()
    error_list.append(err)

plt.figure(figsize=(8, 5))
plt.plot(w_list, error_list, linewidth=2, color='red')
plt.title('Error vs Weight (w) — Find the Valley!')
plt.xlabel('Weight w')
plt.ylabel('Total Error')
plt.grid(True, alpha=0.3)
plt.show()

# 오차가 가장 작은 w 찾기
best_w = w_list[np.argmin(error_list)]
print(f"가장 좋은 w ≈ {best_w:.3f}")
print(f"그때 오차 ≈ {min(error_list):.4f}")
```

### 실습 2-5: 방사선이 $w$를 망가뜨리면?
```python
# 🟢 [실습 2-5] 애써 찾은 w가 방사선을 맞아 망가지면?
import matplotlib.pyplot as plt
import numpy as np

x_data = np.array([150, 160, 170, 180])
y_data = np.array([45,  52,  60,  68])

# 학습 완료! 최적 w를 찾았다고 가정
w_good = 0.77
b_good = 45

# 그런데 방사선이 w의 부호를 뒤집어 버렸다!
w_bad = -0.77  # 방사선 피격!

x_line = np.linspace(140, 190, 50)
plt.figure(figsize=(9, 5))
plt.scatter(x_data, y_data, s=100, color='blue', label='Real data', zorder=5)
plt.plot(x_line, w_good*(x_line-150)+b_good, 'g-', linewidth=2, label=f'Normal AI (w={w_good})')
plt.plot(x_line, w_bad*(x_line-150)+b_good, 'r--', linewidth=2, label=f'Radiated AI (w={w_bad})')

plt.title('What Happens When Cosmic Ray Flips w?')
plt.xlabel('Height (cm)')
plt.ylabel('Weight (kg)')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

print("방사선 한 방에 AI 예측이 완전히 반대 방향으로!")
```

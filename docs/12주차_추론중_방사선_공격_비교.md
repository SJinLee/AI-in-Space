**수업 목표:** 완성된 AI 모델에 **진짜 비트플립** 방사선을 한 번 주입하고 테스트하여, "Training 중 비트플립(11주차)" vs "Inference 중 비트플립(이번 주)" 어느 쪽이 더 치명적인지 수치와 그래프로 증명한다. 방어 클리핑이 어느 쪽에서 더 큰 차이를 만드는지도 함께 본다.

---

## 📖 1. 이론 설명

### 1-1. Inference(추론)란?
Inference는 **"AI가 시험을 보는 중"** 인 상태입니다. 이미 공부가 끝났고(`model.eval()`), 가중치는 고정되어 있죠. 입력을 넣으면 답을 낼 뿐입니다.

$$\hat{y} = f_\text{AI}(x; W_{\text{학습된}})$$

이 상태에서 $W_{\text{학습된}}$ 가 비트플립을 맞으면 어떻게 될까요?

### 1-2. 두 실험의 차이 정리

|  | 11주차: Training 중 비트플립 | 12주차: Inference 중 비트플립 |
|---|---|---|
| 언제 비트플립? | 학습 중 매 epoch마다 | 학습 끝난 후 한 번 |
| 비트플립 횟수 | 여러 번 | 한 번 |
| AI의 대응 | 학습 + 클리핑으로 일부 복구 가능 | 복구 불가능 — 그대로 시험 |
| 비유 | 공부하는 동안 교과서에 낙서당함 | 시험장에서 답안지가 찢어짐 |

### 1-3. 직관적 예측: 어느 쪽이 더 무서울까?

학생들의 직감은 보통 둘로 갈립니다.

> 🧒 "Training 중 비트플립이 더 무서울 것 같아요! 공부가 엉망이 되니까!"
>
> 🧒 "아니야, Inference가 더 무서워요! 시험장에서 답을 틀리잖아요!"

**수학적으로 생각해봅시다:**
- Training 중 비트플립은 여러 번 맞지만, 학습 + 클리핑이 **일부 복구**해줍니다.
- Inference 중 비트플립은 한 번뿐이지만 **즉시 결과에 반영**됩니다. 게다가 9주차에서 봤듯 단 한 칸의 ∞이 모델 출력 전체를 NaN으로 바꿀 수 있어요.

> 💡 **핵심:** 직감만으로는 답할 수 없어요! 같은 확률 $p$ 로 실험해서 비교해봐야 합니다!

### 1-4. 수학적 기대 + 방어의 역할

10주차에서 배운 나비효과 $\text{오차}_n = \text{오차}_1 \times a^{n-1}$ 을 떠올리면, **한 번만 맞아도** 층이 깊으면 증폭되어 큰 피해가 됩니다. Training은 **여러 번** 맞는 대신 학습률(learning rate)과 클리핑으로 부분 완화됩니다.

추론 시에도 마찬가지로 **방어 클리핑**(`harden_weights`)을 켜두는 것이 일반적입니다. 클리핑이 있으면 ∞이 즉시 ±C로 잘려 모델이 살아남습니다.

**가설:** 방어가 있으면 Training이 더 잘 회복하고, 방어가 없으면 Inference 한 방이 모델을 즉사시킨다.

## 💻 2. 실습

### 실습 2-1: 준비 — 11주차 코드 그대로 재활용
```python
# 🟢 [실습 2-1] 11주차에서 가져온 공통 코드
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
import copy
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

transform = transforms.Compose([transforms.ToTensor(),
                                transforms.Normalize((0.1307,), (0.3081,))])
train_set = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_set  = datasets.MNIST('./data', train=False, download=True, transform=transform)
train_loader = DataLoader(train_set, batch_size=128, shuffle=True)
test_loader  = DataLoader(test_set,  batch_size=1000, shuffle=False)

# 9주차의 비트플립 함수 + 11주차의 방어 함수
def apply_space_radiation(weight, probability=0.01, allowed_bits=None):
    if allowed_bits is None:
        allowed_bits = list(range(32))
    device = weight.device
    arr = weight.detach().cpu().contiguous().clone().numpy()
    flat = arr.reshape(-1)
    bits = flat.view(np.uint32)
    hit_mask_np = np.random.rand(flat.size) < probability
    hit_indices = np.where(hit_mask_np)[0]
    bit_positions = np.random.choice(allowed_bits, size=len(hit_indices))
    if len(hit_indices) > 0:
        xor_masks = (np.uint32(1) << bit_positions.astype(np.uint32))
        bits[hit_indices] ^= xor_masks
    return torch.from_numpy(arr.copy()).to(device)

def harden_weights(weight, clip=3.0):
    safe = torch.nan_to_num(weight, nan=0.0, posinf=clip, neginf=-clip)
    return torch.clamp(safe, -clip, clip)

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
        self.relu = nn.ReLU()
    def forward(self, x):
        x = x.view(-1, 784)
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        return self.fc3(x)

def evaluate(model, loader):
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            out = model(x)
            if torch.isnan(out).any() or torch.isinf(out).any():
                out = torch.nan_to_num(out, nan=-1e9, posinf=-1e9, neginf=-1e9)
            correct += (out.argmax(dim=1) == y).sum().item()
            total += y.size(0)
    return 100.0 * correct / total
```

### 실습 2-2: 깨끗한 AI 먼저 만들기 (정상 학습)
```python
# 🟢 [실습 2-2] 방사선 없는 환경에서 정상적으로 학습
torch.manual_seed(0)
clean_model = SimpleNet().to(device)
opt = optim.SGD(clean_model.parameters(), lr=0.01, momentum=0.9)
loss_fn = nn.CrossEntropyLoss()

EPOCHS = 8
for epoch in range(1, EPOCHS + 1):
    clean_model.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()
        loss_fn(clean_model(x), y).backward()
        opt.step()
    print(f"[학습 중] Epoch {epoch}: {evaluate(clean_model, test_loader):.2f}%")

clean_accuracy = evaluate(clean_model, test_loader)
print(f"\n✅ 깨끗한 모델 최종 정확도: {clean_accuracy:.2f}%")

# 매번 같은 출발점에서 실험할 수 있도록 가중치 저장
SAVED_STATE = copy.deepcopy(clean_model.state_dict())
```

### 실습 2-3: Inference 비트플립 — 한 번만 때리고 시험! (방어 O / 방어 X 모두)
```python
# 🟢 [실습 2-3] 완성된 모델에 비트플립 1회, 그리고 테스트
def inference_bitflip_test(probability, defense=True, n_trials=5):
    """비트플립 맞은 모델의 평균 정확도를 반환."""
    accs = []
    for trial in range(n_trials):
        np.random.seed(trial * 31 + int(probability * 100000))
        model = SimpleNet().to(device)
        model.load_state_dict(SAVED_STATE)   # 깨끗한 상태 복원

        # ☢️ 한 번만 비트플립
        with torch.no_grad():
            for param in model.parameters():
                if param.dim() >= 2:
                    flipped = apply_space_radiation(param.data, probability)
                    if defense:
                        flipped = harden_weights(flipped, clip=3.0)
                    param.data = flipped
        accs.append(evaluate(model, test_loader))
    return sum(accs) / len(accs)

# 확률별 Inference 테스트 (두 번: 방어O, 방어X)
prob_list = [0.0001, 0.0005, 0.001, 0.005, 0.01, 0.05]
inf_def_results, inf_nodef_results = [], []
for p in prob_list:
    a_def   = inference_bitflip_test(p, defense=True,  n_trials=5)
    a_nodef = inference_bitflip_test(p, defense=False, n_trials=5)
    inf_def_results.append(a_def)
    inf_nodef_results.append(a_nodef)
    print(f"[Inference {p*100:>5.2f}%] 방어O: {a_def:.2f}%  |  방어X: {a_nodef:.2f}%")
```

### 실습 2-4: Training 비트플립 공격 재실험 (같은 확률로, 방어 O)
```python
# 🟢 [실습 2-4] 11주차 방식 재현: 같은 확률 리스트로 학습 중 비트플립 + 방어
def training_bitflip_test(probability, defense=True):
    """비트플립 환경에서 학습한 모델의 최종 정확도."""
    torch.manual_seed(0)
    np.random.seed(int(probability * 100000))
    model = SimpleNet().to(device)
    opt = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

    for epoch in range(EPOCHS):
        model.train()
        for x, y in train_loader:
            x, y = x.to(device), y.to(device)
            opt.zero_grad()
            out = model(x)
            loss = loss_fn(out, y)
            if torch.isnan(loss) or torch.isinf(loss):
                break    # 방어 X일 때 즉사 가능
            loss.backward()
            opt.step()
        # 매 에폭 끝에 비트플립 (+ 선택적 방어)
        with torch.no_grad():
            for param in model.parameters():
                if param.dim() >= 2:
                    flipped = apply_space_radiation(param.data, probability)
                    if defense:
                        flipped = harden_weights(flipped, clip=3.0)
                    param.data = flipped
    return evaluate(model, test_loader)

train_def_results = []
for p in prob_list:
    acc = training_bitflip_test(p, defense=True)
    train_def_results.append(acc)
    print(f"[Training {p*100:>5.2f}%, 방어O] 최종 정확도: {acc:.2f}%")
```

## 📖 1. 이론 설명

### 1-1. Inference(추론)란?
Inference는 **"AI가 시험을 보는 중"** 인 상태입니다. 이미 공부가 끝났고(model.eval()), 가중치는 고정되어 있죠. 입력을 넣으면 답을 낼 뿐입니다.

$$\hat{y} = f_\text{AI}(x; W_{\text{학습된}})$$

이 상태에서 $W_{\text{학습된}}$ 가 방사선을 맞으면 어떻게 될까요?

### 1-2. 두 실험의 차이 정리

|  | 11주차: Training 중 방사선 | 12주차: Inference 중 방사선 |
|---|---|---|
| 언제 방사선? | 학습 중 매 epoch마다 | 학습 끝난 후 한 번 |
| 방사선 횟수 | 여러 번 | 한 번 |
| AI의 대응 | 업데이트로 어느 정도 복구 가능 | 복구 불가능 — 그대로 시험 |
| 비유 | 공부하는 동안 교과서에 낙서당함 | 시험장에서 문제지가 찢어짐 |

### 1-3. 직관적 예측: 어느 쪽이 더 무서울까?

학생들의 직감은 보통 둘로 갈립니다.

> 🧒 "Training 중 방사선이 더 무서울 것 같아요! 공부가 엉망이 되니까!"
>
> 🧒 "아니야, Inference가 더 무서워요! 시험장에서 답을 틀리잖아요!"

**수학적으로 생각해봅시다:**
- Training 중 방사선은 여러 번 맞지만, 학습 과정이 **일부 복구**해줍니다.
- Inference 중 방사선은 한 번뿐이지만 **즉시 결과에 반영**됩니다.

> 💡 **핵심:** 직감만으로는 답할 수 없어요! 같은 확률 $p$ 로 실험해서 비교해봐야 합니다!

### 1-4. 수학적 기대

10주차에서 배운 나비효과 $\text{오차}_n = \text{오차}_1 \times a^{n-1}$ 을 떠올리면, **한 번만 맞아도** 층이 깊으면 증폭되어 큰 피해가 됩니다. 하지만 Training은 **여러 번** 맞는 대신 학습률(learning rate)로 부분 완화됩니다.

**가설:** 적은 방사선은 Inference가 더 피해가 크고, 많은 방사선은 Training이 더 피해가 클 것이다.

## 💻 2. 실습

### 실습 2-1: 준비 — 11주차 코드 그대로 재활용
```python
# 🟢 [실습 2-1] 11주차에서 가져온 공통 코드
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

transform = transforms.Compose([transforms.ToTensor(),
                                transforms.Normalize((0.1307,), (0.3081,))])
train_set = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_set  = datasets.MNIST('./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_set, batch_size=128, shuffle=True)
test_loader  = DataLoader(test_set,  batch_size=1000, shuffle=False)

def apply_space_radiation(weight, probability=0.01, noise_scale=1.0):
    dice = torch.rand_like(weight)
    hit_mask = dice < probability
    noise = torch.randn_like(weight) * noise_scale
    return weight + hit_mask.float() * noise

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
        self.relu = nn.ReLU()
    def forward(self, x):
        x = x.view(-1, 784)
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        return self.fc3(x)

def evaluate(model, loader):
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            correct += (model(x).argmax(dim=1) == y).sum().item()
            total += y.size(0)
    return 100.0 * correct / total
```

### 실습 2-2: 깨끗한 AI 먼저 만들기 (정상 학습)
```python
# 🟢 [실습 2-2] 방사선 없는 환경에서 정상적으로 학습
torch.manual_seed(0)
clean_model = SimpleNet().to(device)
opt = optim.SGD(clean_model.parameters(), lr=0.01, momentum=0.9)
loss_fn = nn.CrossEntropyLoss()

EPOCHS = 8
for epoch in range(1, EPOCHS + 1):
    clean_model.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()
        loss_fn(clean_model(x), y).backward()
        opt.step()
    print(f"[학습 중] Epoch {epoch}: {evaluate(clean_model, test_loader):.2f}%")

clean_accuracy = evaluate(clean_model, test_loader)
print(f"\n✅ 깨끗한 모델 최종 정확도: {clean_accuracy:.2f}%")

# 이 모델의 가중치를 저장해서 매번 같은 출발점에서 실험
import copy
SAVED_STATE = copy.deepcopy(clean_model.state_dict())
```

### 실습 2-3: Inference 방사선 공격 — 한 번만 때리고 시험!
```python
# 🟢 [실습 2-3] 완성된 모델에 방사선 1회, 그리고 테스트
def inference_radiation_test(probability, noise_scale=0.3, n_trials=5):
    """방사선 맞은 모델의 평균 정확도를 반환"""
    accs = []
    for trial in range(n_trials):
        model = SimpleNet().to(device)
        model.load_state_dict(SAVED_STATE)   # 깨끗한 상태 복원

        # ☢️ 한 번만 방사선 때리기
        with torch.no_grad():
            for param in model.parameters():
                if param.dim() >= 2:
                    param.data = apply_space_radiation(param.data,
                                                       probability,
                                                       noise_scale)
        accs.append(evaluate(model, test_loader))
    return sum(accs) / len(accs)

# 확률별 Inference 테스트
prob_list = [0.001, 0.005, 0.01, 0.02, 0.05, 0.10]
inf_results = []
for p in prob_list:
    acc = inference_radiation_test(p, noise_scale=0.3, n_trials=5)
    inf_results.append(acc)
    print(f"[Inference 방사선 {p*100:>4.1f}%] 평균 정확도: {acc:.2f}%")
```

### 실습 2-4: Training 방사선 공격 재실험 (같은 확률로)
```python
# 🟢 [실습 2-4] 11주차 방식 재현: 같은 확률 리스트로 학습 중 방사선
def training_radiation_test(probability, noise_scale=0.3):
    """방사선 환경에서 학습한 모델의 최종 정확도"""
    torch.manual_seed(0)
    model = SimpleNet().to(device)
    opt = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

    for epoch in range(EPOCHS):
        model.train()
        for x, y in train_loader:
            x, y = x.to(device), y.to(device)
            opt.zero_grad()
            loss_fn(model(x), y).backward()
            opt.step()
        # 매 에폭 끝에 방사선
        with torch.no_grad():
            for param in model.parameters():
                if param.dim() >= 2:
                    param.data = apply_space_radiation(param.data,
                                                       probability,
                                                       noise_scale)
    return evaluate(model, test_loader)

train_results = []
for p in prob_list:
    acc = training_radiation_test(p, noise_scale=0.3)
    train_results.append(acc)
    print(f"[Training 방사선 {p*100:>4.1f}%] 최종 정확도: {acc:.2f}%")
```

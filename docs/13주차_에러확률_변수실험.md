## 📖 1. 이론 설명

### 1-1. 과학 실험의 3가지 변수
과학 시간에 배운 **공정한 실험**의 조건을 기억하나요? 실험이 공정하려면 변수를 잘 정리해야 합니다.

| 변수 이름 | 뜻 | 이번 연구에서 |
|-----------|-----|---------------|
| **조작 변수** | 내가 일부러 바꾸는 값 | 비트플립 발생 확률 (0%, 1%, 5%, 10%, 20%) |
| **통제 변수** | 똑같이 유지하는 값 | 모델 구조(가중치 50개), 입력 분포, 테스트 횟수, 허용 비트(0~31 전부) |
| **반응 변수** | 결과로 측정하는 값 | AI 정확도(%), 평균 오차, NaN/∞ 발생 개수 |

> 💡 **핵심:** "방사선만 바꾸고 나머지는 다 똑같이!" → 이래야 성적 차이가 **방사선 때문**이라고 말할 수 있어요.

### 1-2. 왜 3번 반복해야 할까?
주사위를 한 번만 굴리면 우연히 6이 나올 수도 있죠. 하지만 **30번 굴리면** 1~6이 거의 비슷하게 나옵니다. 이것이 **대수의 법칙**입니다.

우리의 방사선 실험도 **우연**이 섞여 있습니다. 같은 1% 확률이라도 이번엔 3개 맞고, 다음엔 5개 맞고... 그래서 **3회 반복 → 평균**을 냅니다.

$$\text{평균 정확도} = \frac{A_1 + A_2 + A_3}{3}$$

### 1-3. pandas DataFrame: 표 데이터의 마법사
실험을 하면 결과가 잔뜩 쌓입니다. 엑셀처럼 표로 정리해 주는 도구가 바로 **pandas**입니다.

| 방사선 확률 | 실험1 | 실험2 | 실험3 | 평균 |
|:---:|:---:|:---:|:---:|:---:|
| 0% | 98 | 97 | 98 | 97.67 |
| 1% | 95 | 96 | 94 | 95.00 |
| 5% | 78 | 82 | 80 | 80.00 |
| 10% | 45 | 38 | 42 | 41.67 |
| 20% | 12 | 15 | 10 | 12.33 |

> 💡 **핵심:** DataFrame은 엑셀 표와 아주 닮았지만, **파이썬 코드로 자동 계산**이 가능합니다.

### 1-4. 가설 세우기
좋은 과학 연구는 **가설**에서 시작합니다.

> **가설 H1.** 방사선 확률이 커질수록 AI 정확도는 낮아질 것이다. (음의 상관관계)
>
> **가설 H2.** 어느 확률 지점(임계점)을 넘으면 정확도가 급격히 떨어질 것이다.

이 가설을 데이터로 검증해 봅시다!

## 💻 2. 실습: 에러 확률 실험 돌리기

### 실습 2-1: 가짜 AI 모델 만들기 (실험용)
```python
# 🟢 [실습 2-1] 간단한 AI 시뮬레이터
# 진짜 딥러닝은 무겁기 때문에, 오늘은 "곱셈판"으로 AI를 흉내냅니다.

import numpy as np

np.random.seed(42)  # 재현 가능하게!

def make_ai_model(n_weights=50):
    """가짜 AI 모델: float32 가중치 n개. (9주차와 dtype 통일 — 비트플립을 위해 float32 필수)"""
    return (np.random.randn(n_weights) * 0.5).astype(np.float32)

def ai_predict(model, x):
    """AI가 입력 x에 대해 예측: 가중치들의 가중합"""
    return float(np.sum(model * x))

# 모델 만들기
model = make_ai_model(50)
print(f"모델 가중치 개수: {len(model)}")
print(f"가중치 dtype:    {model.dtype}")
print(f"가중치 예시(앞 5개): {model[:5].round(3)}")
```

### 실습 2-2: 방사선 공격 함수 (9주차 비트플립의 numpy 단독 버전)
```python
# 🟢 [실습 2-2] 진짜 비트플립 방사선 발생기

def apply_radiation(model, probability, allowed_bits=None):
    """
    model: float32 가중치 배열
    probability: 각 칸이 비트플립 당할 확률 (0.0 ~ 1.0)
    allowed_bits: 뒤집힐 수 있는 비트 위치 (기본: 0~31 전부)

    Returns: (corrupted, n_hits)  — 9주차 함수와 동일한 인터페이스
    """
    if allowed_bits is None:
        allowed_bits = list(range(32))
    corrupted = model.copy()
    bits = corrupted.view(np.uint32)              # 같은 메모리를 정수로 보기

    dice = np.random.rand(len(model))             # 주사위 굴리기
    hit_mask = dice < probability                 # 당첨된 자리
    hit_indices = np.where(hit_mask)[0]

    if len(hit_indices) > 0:
        bit_positions = np.random.choice(allowed_bits, size=len(hit_indices))
        xor_masks = (np.uint32(1) << bit_positions.astype(np.uint32))
        bits[hit_indices] ^= xor_masks            # XOR로 한 비트만 뒤집기

    return corrupted, int(np.sum(hit_mask))

# 10% 확률로 방사선 쏘아보기
damaged, hits = apply_radiation(model, 0.10)
n_inf = int((~np.isfinite(damaged)).sum())
print(f"방사선에 맞은 가중치 개수: {hits} / {len(model)}")
print(f"  → 그 중 NaN/∞이 된 칸: {n_inf}개")
```

### 실습 2-3: 정확도 측정 함수 (∞/NaN 출력은 자동 오답 처리)
```python
# 🟢 [실습 2-3] AI 성적 채점기

def measure_accuracy(clean_model, damaged_model, n_tests=100):
    """
    깨끗한 모델과 망가진 모델의 예측이 얼마나 비슷한지 측정.
    둘이 같은 방향(부호)으로 예측하면 '맞춘 것'으로 간주.
    비트플립으로 ∞/NaN이 나오면 자동 오답 처리 (실제 망가진 칩이 받는 페널티).
    """
    correct = 0
    total_error = 0.0
    n_invalid = 0

    for _ in range(n_tests):
        x = np.random.randn(len(clean_model)).astype(np.float32)  # 랜덤 입력
        y_clean   = ai_predict(clean_model, x)
        y_damaged = ai_predict(damaged_model, x)

        if not np.isfinite(y_damaged):
            n_invalid += 1     # ∞/NaN 출력 → 오답 + 오차 패널티
            total_error += 100.0
            continue

        if np.sign(y_clean) == np.sign(y_damaged):
            correct += 1
        total_error += abs(y_clean - y_damaged)

    accuracy = correct / n_tests * 100   # 백분율
    avg_error = total_error / n_tests
    return accuracy, avg_error

# 한 번 테스트
damaged, _ = apply_radiation(model, 0.05)
acc, err = measure_accuracy(model, damaged)
print(f"정확도: {acc:.1f}%, 평균 오차: {err:.2f}")
```

### 실습 2-4: 본격 실험! (조작 변수 × 반복)
```python
# 🟢 [실습 2-4] 진짜 실험! 5가지 확률 × 3회 반복 = 15번 실험

import pandas as pd

probabilities = [0.00, 0.01, 0.05, 0.10, 0.20]  # 조작 변수
n_repeats = 3                                    # 반복 횟수

results = []  # 빈 리스트에 결과 하나씩 쌓기

for p in probabilities:
    for trial in range(1, n_repeats + 1):
        damaged, hits = apply_radiation(model, p)
        acc, err = measure_accuracy(model, damaged, n_tests=200)
        n_inf = int((~np.isfinite(damaged)).sum())

        results.append({
            "확률(%)": p * 100,
            "실험회차": trial,
            "맞은_가중치": hits,
            "NaN_∞_개수": n_inf,
            "정확도(%)": round(acc, 2),
            "평균오차": round(err, 3),
        })
        print(f"  확률 {p*100:>4.0f}% | 회차 {trial} | "
              f"명중 {hits:>2} (∞:{n_inf}) | 정확도 {acc:>5.1f}% | 오차 {err:.2f}")

# DataFrame으로 변환!
df = pd.DataFrame(results)
print("\n===== 전체 실험 결과 =====")
print(df.to_string(index=False))
```

### 실습 2-5: 평균 구하고 저장하기
```python
# 🟢 [실습 2-5] 확률별 평균 정리 + CSV 저장

# 확률별로 평균 내기 (groupby는 pandas의 꽃!)
summary = df.groupby("확률(%)").agg(
    평균정확도=("정확도(%)", "mean"),
    표준편차=("정확도(%)", "std"),
    평균오차=("평균오차", "mean"),
).round(2).reset_index()

print("===== 확률별 평균 요약 =====")
print(summary.to_string(index=False))

# CSV로 저장 (엑셀에서도 열 수 있어요!)
df.to_csv("실험원본데이터.csv", index=False, encoding="utf-8-sig")
summary.to_csv("실험요약.csv", index=False, encoding="utf-8-sig")
print("\n💾 CSV 파일 2개 저장 완료!")
```

## 📖 1. 이론 설명

### 1-1. 파이썬 기본 문법 맛보기
파이썬 코드는 **위에서 아래로** 한 줄씩 실행됩니다. 가장 먼저 배울 세 가지는 다음과 같습니다.

| 문법 | 하는 일 | 예시 |
|------|---------|------|
| 변수 | 숫자/글자를 상자에 담아두기 | `x = 10` |
| 반복문 | 같은 일을 여러 번 하기 | `for i in range(5):` |
| 조건문 | "만약 ~라면" 하고 분기 | `if x > 0:` |

> 💡 **핵심:** 변수는 '이름표를 붙인 상자'이고, 반복문과 조건문은 컴퓨터에게 **"이걸 반복해!"**, **"이럴 땐 이렇게 해!"** 라고 명령하는 문법입니다.

### 1-2. 수학의 함수 $f(x) = y$
중학교 수학에서 함수란 **"$x$ 값 하나에 $y$ 값 하나가 정해지는 관계"** 였습니다.

$$f(x) = 2x + 3$$

| $x$ (입력) | 계산 | $y$ (출력) |
|------------|------|------------|
| 0 | $2 \times 0 + 3$ | 3 |
| 1 | $2 \times 1 + 3$ | 5 |
| 5 | $2 \times 5 + 3$ | 13 |
| 10 | $2 \times 10 + 3$ | 23 |

입력이 하나 들어가면 출력이 하나 정확하게 튀어나오는 **계산 기계**입니다.

### 1-3. 함수 = 자판기 🥤
자판기는 어떻게 동작할까요?

| 자판기 | 파이썬 함수 | 수학 함수 |
|--------|-------------|-----------|
| 동전 500원 투입 | 입력 매개변수(argument) | $x$ |
| 내부 전자 회로 처리 | 함수 몸통(body) | 계산식 |
| 콜라가 나옴 | `return` (반환값) | $y$ |

동전을 넣으면(입력) → 기계가 돌아가며(처리) → 콜라가 나옵니다(출력). 파이썬 함수도 똑같습니다!

```
 [500원] ──▶ ┌────────────┐ ──▶ [콜라 🥤]
              │  자판기     │
              │ (함수 몸통) │
              └────────────┘
```

> 💡 **핵심:** 수학 함수 $f(x)=y$ 와 파이썬 함수 `def f(x): return y` 는 **똑같은 개념**입니다!

### 1-4. 왜 함수가 AI의 핵심 부품일까?
인공지능(AI)은 결국 **수많은 함수를 이어붙인 거대한 계산 구조물**입니다.

- 한 개의 함수: $y = 2x + 3$ (간단)
- 두 개 이어붙이기: $z = f(g(x))$ (조금 복잡)
- 수백만 개 이어붙이기: **인공지능 모델** 🤖

> ⚠️ **미리 알려드립니다:** 오늘 만드는 간단한 '2배 함수' 하나가 5~6주차에는 일차함수 $y = ax + b$ 로 확장되고, 10주차에는 AI 신경망의 한 부품이 됩니다!

### 실습 2-2: 내 첫 함수 — 2배 자판기
```python
# 🟢 [실습 2-2] x를 넣으면 2배로 돌려주는 자판기 만들기

def 두배자판기(x):
    """x를 넣으면 2배로 돌려주는 마법 상자"""
    y = 2 * x
    return y

# 자판기에 여러 숫자를 넣어보기
for 입력 in [1, 3, 5, 10, 100]:
    결과 = 두배자판기(입력)
    print(f"입력 {입력:>3} → 자판기 → 출력 {결과}")
```

### 실습 2-3: 일차함수 $f(x) = 2x + 3$ 자판기
```python
# 🟢 [실습 2-3] 수학시간에 배운 일차함수를 파이썬으로!

def f(x):
    return 2 * x + 3

# 수학책 표처럼 입력과 출력을 나란히 출력
print(" x  |  f(x)")
print("----+------")
for x in range(0, 6):
    print(f" {x}  |  {f(x)}")

# 검산: f(5) = 2×5 + 3 = 13 인지 확인
print()
print(f"검산: f(5) = 2×5 + 3 = {f(5)} ✅")
```

### 실습 2-4: 두 함수 이어붙이기 (AI의 맛보기)
```python
# 🟢 [실습 2-4] 함수 두 개를 이어붙이면? (AI의 기본 아이디어)

def 함수1(x):
    return 2 * x        # 2배 해주는 자판기

def 함수2(x):
    return x + 10       # 10을 더해주는 자판기

# 함수1의 결과를 다시 함수2에 넣어보기
입력 = 5
중간 = 함수1(입력)       # 5 → 10
최종 = 함수2(중간)       # 10 → 20

print(f"입력: {입력}")
print(f"함수1(2배) 통과 후: {중간}")
print(f"함수2(+10) 통과 후: {최종}")
print()
print("💡 이렇게 함수를 수백만 개 이어붙인 게 바로 '인공지능(AI)' 입니다!")
```

### 실습 2-5: 함수가 고장 난다면? (방사선 미리보기)
```python
# 🟢 [실습 2-5] 자판기(함수)가 방사선을 맞아 고장 나면?

def 정상자판기(x):
    return 2 * x + 3     # 원래는 2를 곱해야 함

def 고장난자판기(x):
    return 2.1 * x + 3   # 방사선 때문에 2가 2.1로 바뀜!

print(" x  | 정상 | 고장 | 차이")
print("----+------+------+------")
for x in [1, 10, 100, 1000]:
    정상 = 정상자판기(x)
    고장 = 고장난자판기(x)
    차이 = round(고장 - 정상, 2)
    print(f" {x:>4} | {정상:>4} | {고장:>5} | {차이}")

print()
print("⚠️ x가 커질수록 차이가 더 벌어집니다! 이게 바로 '나비효과' 입니다.")
```

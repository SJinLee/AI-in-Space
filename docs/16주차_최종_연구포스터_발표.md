### 1-2. 연구 포스터의 7대 요소
학술 포스터는 정해진 구조가 있습니다.

| 번호 | 섹션 | 무엇을 담나? | 분량 |
|:---:|------|-------------|:---:|
| 1 | **제목(Title)** | 눈에 띄는 주제 + 연구자 이름 | 1줄 |
| 2 | **동기(Motivation)** | 왜 이 연구를 시작했나? | 3~4줄 |
| 3 | **가설(Hypothesis)** | 예측한 답 | 1~2줄 |
| 4 | **방법(Methods)** | 어떻게 실험했나? | 4~6줄 |
| 5 | **결과(Results)** | 그래프 3종 + 표 | 핵심! |
| 6 | **결론(Conclusion)** | 가설 검증 + 의미 | 3~4줄 |
| 7 | **방어 전략** | 제안하는 해결책 | 3~4줄 |

### 1-3. 그래프 3종 세트
좋은 포스터에는 다음 3개의 그래프가 들어갑니다.

1. **산점도(Scatter Plot)** — 방사선 확률 vs AI 정확도
2. **추세선 그래프** — 임계점이 표시된 흐름 분석
3. **방어 전략 막대 그래프** — Clipping/TMR/Ensemble 비교

### 1-4. 발표의 3박자: 구조 / 시선 / 목소리
- **구조**: "무엇을 → 왜 → 어떻게 → 결과 → 결론" 순서
- **시선**: 청중의 눈을 3명 이상 번갈아 보기
- **목소리**: 중요한 단어에서 잠깐 멈추기 (예: "임계점은... **5%** 였습니다")

### 실습 2-1: 포스터용 산점도 그래프 (고해상도)
```python
# 🟢 [실습 2-1] 포스터용 메인 그래프

import numpy as np
import matplotlib.pyplot as plt
import pandas as pd

prob = np.array([0, 1, 5, 10, 20])
acc = np.array([97.67, 95.00, 80.00, 41.67, 12.33])
std = np.array([0.58, 1.00, 2.00, 3.50, 2.50])

fig, ax = plt.subplots(figsize=(10, 6), dpi=200)  # 고해상도!

ax.errorbar(prob, acc, yerr=std, fmt='o', color='crimson',
            ecolor='gray', markersize=14, capsize=6, 
            linewidth=2, label='Experiment (mean ± std)')
ax.plot(prob, acc, color='navy', linestyle='--', linewidth=2, label='Trend')

# 임계점 강조
ax.axvspan(5, 10, color='gold', alpha=0.25, label='Threshold zone')
ax.annotate('CRITICAL\nCOLLAPSE!', xy=(7.5, 60), fontsize=12,
            ha='center', color='darkred', fontweight='bold')

ax.set_title('Graph 1: Radiation Probability vs AI Accuracy', fontsize=15)
ax.set_xlabel('Radiation Probability (%)', fontsize=12)
ax.set_ylabel('AI Accuracy (%)', fontsize=12)
ax.set_ylim(0, 105)
ax.grid(True, alpha=0.4)
ax.legend(loc='upper right', fontsize=11)
plt.tight_layout()
plt.savefig('poster_graph1.png', dpi=200)
plt.show()
```

### 실습 2-2: 방어 전략 비교 막대 그래프

```python
# 🟢 [실습 2-2] 방어 전략 비교용 그래프

defense_data = pd.DataFrame({
    '확률(%)':  [1, 5, 10, 20],
    '방어없음': [95, 80, 42, 12],
    'Clipping': [96, 85, 60, 25],
    'TMR':      [97, 92, 80, 55],
    'Ensemble': [97, 94, 85, 65],
})

fig, ax = plt.subplots(figsize=(10, 6), dpi=200)
x = np.arange(len(defense_data))
width = 0.2
colors = ['#d62728', '#ff7f0e', '#2ca02c', '#1f77b4']
labels = ['방어없음', 'Clipping', 'TMR', 'Ensemble']

for i, name in enumerate(labels):
    ax.bar(x + i*width, defense_data[name], width, 
           label=name, color=colors[i], edgecolor='black')

ax.set_xticks(x + width*1.5)
ax.set_xticklabels([f"{p}%" for p in defense_data['확률(%)']])
ax.set_xlabel('Radiation Probability', fontsize=12)
ax.set_ylabel('AI Accuracy (%)', fontsize=12)
ax.set_title('Graph 2: Defense Strategy Comparison', fontsize=15)
ax.legend(fontsize=11)
ax.grid(axis='y', alpha=0.4)
ax.set_ylim(0, 105)
plt.tight_layout()
plt.savefig('poster_graph2.png', dpi=200)
plt.show()
```

### 실습 2-3: 나비효과 시각화 그래프 (오차 증폭)
```python
# 🟢 [실습 2-3] 나비효과 증명 그래프

floors = np.arange(1, 11)
normal = np.ones(10) * 1.0       # 오차 없음
error_small = 1.05 ** floors     # 5% 초기 오차가 곱해짐
error_big   = 1.15 ** floors     # 15% 초기 오차

fig, ax = plt.subplots(figsize=(10, 6), dpi=200)
ax.plot(floors, normal, 'o-', color='green', linewidth=2, label='No error')
ax.plot(floors, error_small, 's-', color='orange', linewidth=2, label='5% initial error')
ax.plot(floors, error_big, '^-', color='red', linewidth=2, label='15% initial error')

ax.set_title('Graph 3: Butterfly Effect — Error Amplification', fontsize=15)
ax.set_xlabel('AI Layer (Floor)', fontsize=12)
ax.set_ylabel('Value at each layer', fontsize=12)
ax.legend(fontsize=11)
ax.grid(True, alpha=0.4)
plt.tight_layout()
plt.savefig('poster_graph3.png', dpi=200)
plt.show()
```

```python
✅ 결론
   AI의 생존은 '확률의 임계점'에 의해 결정된다. 방사선이
   일정 수준을 넘으면 지능은 비선형적으로 붕괴하지만,

============================================================
```

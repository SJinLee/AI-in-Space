## 📖 1. 이론 설명

### 1-1. 왜 방어가 필요할까?
14주차에서 확인했듯, 5~10% 구간부터 AI는 **절벽처럼** 무너집니다. 하지만 NASA의 인공위성이나 스페이스X의 로켓은 **실제로 잘 작동**합니다. 왜일까요?

정답은 **오류 정정(Error Correction)** 기술 덕분입니다. 수학과 중복성(redundancy)을 이용해 에러를 **검출하고 복구**합니다.

> 💡 **핵심:** "에러가 생기지 않게 막는 것"이 어렵다면, "에러가 생겨도 되살리는 방법"을 쓰자!

### 1-2. 방어 전략 1 — Clipping (큰 값 잘라내기) ✂️
9~12주차에서 봤듯, 비트플립이 지수(E) 비트에 맞으면 가중치가 **±∞이나 거대한 수**가 됩니다. 정상 가중치는 -1 ~ 1 사이인데 갑자기 ∞가 나오면 수상하죠.

$$\text{clip}(x, -T, T) = \begin{cases} -T & (x < -T) \\ x & (-T \le x \le T) \\ T & (x > T) \end{cases}$$

여기서 $T$는 한계값(threshold). 너무 큰 값은 **잘라서** 정상 범위로 끌어당깁니다. 실무에서는 `nan_to_num` 으로 NaN과 ∞을 먼저 정리한 뒤 clip을 적용합니다(11주차 `harden_weights`).

**비유:** "지각 벌점이 아무리 나빠도 -5점까지만 깎는다" 같은 규칙.

### 1-3. 방어 전략 2 — TMR (Triple Modular Redundancy) 🗳️
**TMR**은 실제 우주용 컴퓨터의 핵심 기법입니다. 같은 계산을 **3개의 복사본**이 동시에 하고, **다수결(중앙값)** 로 답을 정합니다.

| 복사본 A | 복사본 B | 복사본 C | 중앙값 결과 |
|:---:|:---:|:---:|:---:|
| 42 | 42 | **999** (비트플립!) | 42 ✅ |
| 42 | 42 | **∞** (지수 비트 맞음!) | **42** ✅ ← 평균이라면 ∞이 됨! |
| 42 | **999** | **−100** | **42** (가운데 값) |

$$\text{result} = \text{median}(A, B, C)$$

**비유:** 3명의 심판 중 한 명이 미쳐도(=∞이 나와도) 가운데 값을 고르면 정상값이 살아남는다.

### 1-4. 방어 전략 3 — Ensemble (평균 내기) 📊
여러 개의 AI 모델을 만들어 예측을 **평균**하는 방법입니다.

$$\bar{y} = \frac{y_1 + y_2 + \cdots + y_n}{n}$$

한두 개의 모델이 방사선에 맞아도 나머지 정상 모델들의 **평균**이 에러를 희석시킵니다.

> ⚠️ **단, 비트플립이 ∞을 만들면 평균은 즉시 무력해진다!** $\text{mean}(42, 42, \infty) = \infty$. 그래서 진짜 비트플립 환경에서는 Ensemble을 쓰기 전에 **반드시 `nan_to_num` 으로 ∞/NaN을 먼저 정리**해야 합니다. 평균이 중앙값보다 이상치(outlier)에 약하다는 중2 통계의 통찰이 여기 그대로 적용됩니다.

**비유:** 시험 5과목 평균인데 한 과목이 "∞점"으로 잘못 채점되면 평균도 ∞ — 먼저 비정상 점수를 잡아낸 뒤 평균을 내야 합니다.

### 1-5. 방어 전략 4 — Parity Bit (패리티 / 체크섬) 🔍
데이터에 **검사용 비트**를 덧붙여 오류를 **감지**하는 방법입니다.

예: 원본 데이터가 `[1, 0, 1, 1]` → 1의 개수가 **3개(홀수)** → 패리티 비트 **1** 추가 → `[1, 0, 1, 1, 1]`

데이터가 도착하면 다시 1의 개수를 셉니다. 짝수가 되어야 정상! 홀수면 "어딘가 에러!" 경보!

> 💡 **핵심:** 패리티는 "에러 발견"은 가능하지만 "에러 복구"는 어렵습니다. TMR/Ensemble과 함께 쓰면 강력해집니다.

### 1-6. 방어 전략 비교표

| 전략 | 핵심 수학 | 비용(자원) | ∞ 면역? | 복구 능력 |
|------|-----------|:---:|:---:|:---:|
| Clipping | 범위 제한 $\min/\max$ + `nan_to_num` | 낮음 | ✅ | 중간 |
| TMR | 중앙값(median) | 3배 | ✅ (자연 면역) | 높음 |
| Ensemble | 산술평균 | $n$배 | ❌ (전처리 필수) | 높음 |
| Parity | 덧셈 mod 2 | 매우 낮음 | — | 검출만 |

### 실습 2-1: 기본 세팅 (14주차 코드 이어서)
```python
# 🟢 [실습 2-1] 실험 준비

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

np.random.seed(2026)

def make_model(n=50):
    """간단한 float32 모델(가중치 벡터). 9~12주차의 비트플립 모델과 dtype 통일."""
    return (np.random.randn(n) * 0.5).astype(np.float32)

def apply_radiation(model, p, allowed_bits=None):
    """진짜 비트플립(9주차 함수의 numpy 버전). float32 한 칸이 ∞/NaN이 될 수도 있음."""
    if allowed_bits is None:
        allowed_bits = list(range(32))
    corrupted = model.copy()
    bits = corrupted.view(np.uint32)
    hit_mask = np.random.rand(len(model)) < p
    hit_indices = np.where(hit_mask)[0]
    if len(hit_indices) > 0:
        bit_positions = np.random.choice(allowed_bits, size=len(hit_indices))
        xor_masks = (np.uint32(1) << bit_positions.astype(np.uint32))
        bits[hit_indices] ^= xor_masks
    return corrupted

def predict(model, x):
    return float(np.sum(model * x))

def measure(clean, test_model, n=200):
    """정확도 측정 — NaN/∞ 출력은 자동으로 오답 처리."""
    correct = 0
    for _ in range(n):
        x = np.random.randn(len(clean)).astype(np.float32)
        p_clean = predict(clean, x)
        p_test  = predict(test_model, x)
        if not np.isfinite(p_test):
            continue   # ∞/NaN 출력은 오답
        if np.sign(p_clean) == np.sign(p_test):
            correct += 1
    return correct / n * 100

clean_model = make_model(50)
print("✅ 기본 세팅 완료 (진짜 비트플립 모델 사용)")
```

### 실습 2-2: 방어 전략 1 — Clipping
```python
# 🟢 [실습 2-2] 큰 값 잘라내기 방어! (∞/NaN도 함께 처리)

def defense_clipping(model, threshold=2.0):
    """∞ → ±threshold, NaN → 0, |w|>threshold → ±threshold."""
    safe = np.nan_to_num(model, nan=0.0, posinf=threshold, neginf=-threshold)
    return np.clip(safe, -threshold, threshold)

# 테스트
np.random.seed(2026)
damaged = apply_radiation(clean_model, 0.10)
defended = defense_clipping(damaged, threshold=2.0)

print(f"방어 없음 (∞ 포함):  정확도 = {measure(clean_model, damaged):.1f}%")
print(f"Clipping:           정확도 = {measure(clean_model, defended):.1f}%")
print(f"→ 망가진 모델 NaN/∞ 개수: {(~np.isfinite(damaged)).sum()}")
print(f"→ 방어 후 NaN/∞ 개수:   {(~np.isfinite(defended)).sum()}")
```

### 실습 2-3: 방어 전략 2 — TMR (다수결, 중앙값)
```python
# 🟢 [실습 2-3] 3번 찍어 다수결! 중앙값(median)은 ∞에 자연 면역!

def defense_tmr(clean_model, probability):
    """같은 모델을 3번 복사해서 각각 비트플립 맞추고, 가중치별 중앙값 선택."""
    copy_A = apply_radiation(clean_model, probability)
    copy_B = apply_radiation(clean_model, probability)
    copy_C = apply_radiation(clean_model, probability)
    
    # 3개 값의 중앙값 → 한 칸이 ∞이어도 나머지 둘이 정상이면 정상값 선택!
    stacked = np.stack([copy_A, copy_B, copy_C], axis=0)
    voted = np.median(stacked, axis=0)
    return voted

# 10% 확률로 테스트
p = 0.10
np.random.seed(2026)
no_defense = apply_radiation(clean_model, p)
np.random.seed(2026)
tmr_result = defense_tmr(clean_model, p)

print(f"방어 없음: {measure(clean_model, no_defense):.1f}%   (NaN/∞: {(~np.isfinite(no_defense)).sum()}개)")
print(f"TMR 방어:  {measure(clean_model, tmr_result):.1f}%   (NaN/∞: {(~np.isfinite(tmr_result)).sum()}개)")
print("\n💡 median([42, 42, ∞]) = 42 — 중앙값은 한 점의 ∞에 면역!")
print("   이게 다음 셀의 Ensemble(평균)과 결정적으로 다른 점입니다.")
```

### 실습 2-4: 방어 전략 3 — Ensemble (평균) + 평균이 ∞에 약한 이유
```python
# 🟢 [실습 2-4] 여러 모델 평균내기! — 단, 평균은 ∞ 한 점에 무력

def defense_ensemble_naive(clean_model, probability, n_models=5):
    """순진한 평균 — 한 칸이라도 ∞이면 그 자리는 평균도 ∞이 된다."""
    copies = [apply_radiation(clean_model, probability) for _ in range(n_models)]
    return np.mean(copies, axis=0)

def defense_ensemble_safe(clean_model, probability, n_models=5):
    """∞/NaN을 먼저 정리한 뒤 평균 — 실제 위성 컴퓨터의 권장 방식."""
    copies = [apply_radiation(clean_model, probability) for _ in range(n_models)]
    cleaned = [np.nan_to_num(c, nan=0.0, posinf=10.0, neginf=-10.0) for c in copies]
    return np.mean(cleaned, axis=0)

np.random.seed(2026)
ensemble_naive = defense_ensemble_naive(clean_model, 0.10, n_models=5)
np.random.seed(2026)
ensemble_safe  = defense_ensemble_safe (clean_model, 0.10, n_models=5)

print(f"방어 없음:                {measure(clean_model, no_defense):.1f}%")
print(f"Ensemble 순진한 평균:     {measure(clean_model, ensemble_naive):.1f}%   "
      f"(NaN/∞: {(~np.isfinite(ensemble_naive)).sum()}개)")
print(f"Ensemble + nan_to_num:   {measure(clean_model, ensemble_safe):.1f}%   "
      f"(NaN/∞: {(~np.isfinite(ensemble_safe)).sum()}개)")
print("\n💡 핵심 수학 통찰:")
print("   median([42, 42, ∞]) = 42  → 중앙값은 ∞에 면역")
print("   mean([42, 42, ∞])   = ∞   → 평균은 ∞ 한 점에 즉사")
print("   → 그래서 진짜 비트플립 환경에서는 TMR(중앙값)이 단순 Ensemble보다 강건합니다.")
```

### 실습 2-5: 방어 전략 4 — Parity Bit (에러 검출)
```python
# 🟢 [실습 2-5] 패리티 비트로 에러 감지!

def compute_parity(bits):
    """1의 개수가 짝수가 되도록 패리티 비트 추가."""
    return int(np.sum(bits) % 2)  # 홀수면 1, 짝수면 0

def check_parity(bits_with_parity):
    """전체 1의 개수가 짝수면 OK, 홀수면 에러 감지!"""
    return np.sum(bits_with_parity) % 2 == 0

# 예시: 4비트 데이터
data = np.array([1, 0, 1, 1])
parity = compute_parity(data)
packet = np.append(data, parity)
print(f"보낼 패킷: {packet} (패리티 = {parity})")

# 정상 수신
print(f"정상 수신 검사: {'✅ OK' if check_parity(packet) else '❌ ERROR'}")

# 방사선이 한 비트 뒤집음!
corrupted = packet.copy()
corrupted[1] ^= 1  # XOR로 비트 뒤집기
print(f"방사선 맞은 패킷: {corrupted}")
print(f"에러 검사: {'✅ OK' if check_parity(corrupted) else '❌ ERROR (에러 감지!)'}")
```

### 실습 2-6: 방어 전략 종합 비교 그래프
```python
# 🟢 [실습 2-6] 모든 방어 전략 한눈에 비교! (Ensemble을 두 버전 모두 표시)

probabilities = [0.01, 0.05, 0.10, 0.20]
results = {"없음": [], "Clipping": [], "TMR": [],
           "Ensemble (naive)": [], "Ensemble (safe)": []}

for p in probabilities:
    np.random.seed(2026)
    d0 = apply_radiation(clean_model, p)
    results["없음"].append(measure(clean_model, d0))

    np.random.seed(2026)
    d1 = defense_clipping(apply_radiation(clean_model, p), threshold=2.0)
    results["Clipping"].append(measure(clean_model, d1))

    np.random.seed(2026)
    d2 = defense_tmr(clean_model, p)
    results["TMR"].append(measure(clean_model, d2))

    np.random.seed(2026)
    d3a = defense_ensemble_naive(clean_model, p, n_models=5)
    results["Ensemble (naive)"].append(measure(clean_model, d3a))

    np.random.seed(2026)
    d3b = defense_ensemble_safe(clean_model, p, n_models=5)
    results["Ensemble (safe)"].append(measure(clean_model, d3b))

df = pd.DataFrame(results, index=[f"{int(p*100)}%" for p in probabilities])
print(df.round(1))
print("\n💡 'Ensemble (naive)' 가 'Ensemble (safe)' 보다 낮으면, 그게 바로 평균이 ∞에 무력하다는 증거!")

# 그래프
plt.figure(figsize=(11, 6))
x = np.arange(len(probabilities))
n_strategies = len(results)
width = 0.85 / n_strategies
colors = ['#d62728', '#ff7f0e', '#2ca02c', '#9467bd', '#1f77b4']

for i, (name, vals) in enumerate(results.items()):
    plt.bar(x + i*width, vals, width, label=name, color=colors[i])

plt.xticks(x + width*(n_strategies-1)/2, [f"{int(p*100)}%" for p in probabilities])
plt.xlabel('Bit-flip Probability')
plt.ylabel('AI Accuracy (%)')
plt.title('Defense Strategy Comparison (under real bit-flip)')
plt.ylim(0, 105)
plt.legend(fontsize=9)
plt.grid(axis='y', alpha=0.4)
plt.tight_layout()
plt.savefig('15주차_방어비교.png', dpi=150)
plt.show()
```

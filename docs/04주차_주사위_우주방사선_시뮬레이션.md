## 📖 1. 이론 설명

### 1-1. 난수(Random Number)란?
**난수**는 "다음에 어떤 값이 나올지 미리 알 수 없는 숫자" 입니다.

| 상황 | 난수의 예 |
|------|-----------|
| 주사위 굴리기 | 1~6 중 하나 |
| 동전 던지기 | 앞(1) 또는 뒤(0) |
| 로또 번호 추첨 | 1~45 중 6개 |
| 파이썬 `random.random()` | 0.0 ~ 1.0 사이 실수 |

> 💡 **핵심:** 컴퓨터는 '가짜 난수(의사 난수)'를 만들어 진짜 주사위처럼 사용합니다. 이걸로 우주 방사선도 흉내 낼 수 있습니다!

### 1-2. 중2 확률: 경우의 수와 상대도수
중학교 2학년 때 배우는 **확률의 정의**는 다음과 같습니다.

$$\text{확률} = \frac{\text{사건이 일어나는 경우의 수}}{\text{모든 경우의 수}}$$

| 상황 | 확률 |
|------|------|
| 주사위에서 1이 나올 확률 | $\frac{1}{6} \approx 16.7\%$ |
| 동전에서 앞면이 나올 확률 | $\frac{1}{2} = 50\%$ |
| 로또 1등 당첨 확률 | $\frac{1}{8{,}145{,}060} \approx 0.00001\%$ |

**상대도수**는 많은 횟수로 시험했을 때 실제로 일어난 비율입니다. 시험 횟수가 많을수록 **이론 확률에 가까워집니다** (큰 수의 법칙).

### 1-3. 1% 확률 만들기 아이디어
컴퓨터의 `random()` 함수는 **0.0 ~ 1.0 사이의 실수**를 무작위로 뽑습니다.

> 💡 **아이디어:** 뽑은 숫자가 **0.01 보다 작으면 당첨!** 이라고 정하면, 당첨될 확률이 정확히 **1%** 입니다.

| 뽑힌 난수 | 0.01 미만? | 결과 |
|-----------|------------|------|
| 0.003 | ✅ | 당첨 (1%) |
| 0.52 | ❌ | 꽝 |
| 0.009 | ✅ | 당첨 (1%) |
| 0.99 | ❌ | 꽝 |

이 방법을 **확률 실험(probabilistic experiment)** 이라고 합니다.

### 1-4. 우주 방사선 에러 시뮬레이터의 원리
우주에서는 1초마다 방사선 입자가 무작위로 날아와 칩을 때립니다.

$$\text{방사선 모델} = \text{1\% 확률 주사위} \times \text{10,000개 숫자}$$

| 무엇 | 시뮬레이션에서 |
|------|----------------|
| 칩 속의 숫자 10,000개 | Numpy 배열 길이 10,000 |
| 방사선 입자가 랜덤으로 때림 | `np.random.rand(10000)` |
| 1% 확률로 명중 | `난수 < 0.01` |
| 명중한 비트가 뒤집힘 | 그 위치의 숫자 **부호 반전** ($x \to -x$) |

> ⚠️ **주의:** 이론상 10,000개 중 100개가 맞아야 하지만, 실제로는 **98개, 105개, 87개** 처럼 약간씩 달라집니다. 이게 바로 '상대도수' 개념!

### 실습 4-1: 난수 맛보기

```python
# 🟢 [실습 4-1] 파이썬 주사위 굴려보기
import random

# 0.0 ~ 1.0 사이 난수 5번 뽑기
print("0~1 사이 난수 5개:")
for i in range(5):
    print(f"  {i+1}번째: {random.random():.4f}")

# 1~6 주사위 10번 굴리기
print("\n주사위 10번 굴리기:")
주사위_결과 = [random.randint(1, 6) for _ in range(10)]
print(주사위_결과)
```

### 실습 4-2: 1% 확률 게임 (작은 규모 관찰)
```python
# 🟢 [실습 4-2] 1% 확률 만들기 게임
import random

시행횟수 = 100
당첨횟수 = 0

for _ in range(시행횟수):
    난수 = random.random()      # 0~1 사이 난수 뽑기
    if 난수 < 0.01:             # 1% 조건
        당첨횟수 += 1

print(f"총 시행 횟수: {시행횟수}")
print(f"당첨 횟수: {당첨횟수}")
print(f"실제 상대도수: {당첨횟수 / 시행횟수 * 100:.1f}%")
print(f"이론 확률: 1.0%")
```

### 실습 4-3: 시행 횟수가 많아질수록? (큰 수의 법칙)
```python
# 🟢 [실습 4-3] 시험 횟수가 많아지면 상대도수가 1%에 가까워질까?
import random

print(" 시행횟수 | 당첨 | 상대도수")
print("----------+-------+---------")

for 시행횟수 in [100, 1000, 10000, 100000]:
    당첨 = sum(1 for _ in range(시행횟수) if random.random() < 0.01)
    상대도수 = 당첨 / 시행횟수 * 100
    print(f" {시행횟수:>8} | {당첨:>5} | {상대도수:>5.2f}%")

print("\n💡 시행 횟수가 많을수록 이론값(1%)에 가까워집니다! (큰 수의 법칙)")
```

### 실습 4-4: Numpy로 10,000개 숫자에 방사선 쏘기!
```python
# 🟢 [실습 4-4] 10,000개 숫자에 1% 방사선 시뮬레이션!
import numpy as np

# 1) 깨끗한 데이터 10,000개 만들기 (모두 1)
data = np.ones(10000)
print(f"원본 데이터 합계: {data.sum():.0f} (= 10000)")

# 2) 방사선 주사위 10,000번 굴리기
주사위 = np.random.rand(10000)   # 0~1 사이 난수 10,000개

# 3) 1% 당첨된 위치만 True로 표시
방사선_맞음 = 주사위 < 0.01

# 4) 당첨된 자리의 숫자 부호를 뒤집기! (1 → -1)
data[방사선_맞음] = -data[방사선_맞음]

# 5) 결과 확인
맞은_개수 = 방사선_맞음.sum()
print(f"\n⚡ 방사선 맞은 숫자 개수: {맞은_개수}개 (이론 기대값: 100개)")
print(f"상대도수: {맞은_개수/10000*100:.2f}%")
print(f"방사선 후 데이터 합계: {data.sum():.0f}")
print(f"→ 원래 10000이었는데 {10000 - int(data.sum())} 만큼 줄어들었습니다!")
```

### 실습 4-5: 방사선 강도 실험 (확률 비교)
```python
# 🟢 [실습 4-5] 확률을 바꾸면 에러는 얼마나 늘까?
import numpy as np

print("방사선 강도별 에러 개수 (10,000개 중):")
print(" 확률   | 이론값 | 실제값 | 상대도수")
print("--------+--------+--------+--------")

for 확률 in [0.001, 0.01, 0.05, 0.10, 0.20]:
    data = np.ones(10000)
    주사위 = np.random.rand(10000)
    방사선_맞음 = 주사위 < 확률
    맞은_개수 = int(방사선_맞음.sum())
    이론값 = int(10000 * 확률)
    상대도수 = 맞은_개수 / 10000 * 100
    print(f" {확률*100:>4.1f}% | {이론값:>6} | {맞은_개수:>6} | {상대도수:>5.2f}%")

print("\n💡 확률이 커질수록 에러도 비례해서 늘어납니다.")
print("   나중에 이 확률이 AI 정답률에 어떤 영향을 주는지 분석합니다!")
```

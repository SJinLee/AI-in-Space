## 📖 1. 이론 설명

### 1-1. 난수(Random Number)란?
**난수**는 "다음에 어떤 값이 나올지 미리 알 수 없는 숫자" 입니다.

| 상황 | 난수의 예 |
|------|-----------|
| 주사위 굴리기 | 1~6 중 하나 |
| 동전 던지기 | 앞(1) 또는 뒤(0) |
| 로또 번호 추첨 | 1~45 중 6개 |
| 파이썬 `random.random()` | 0.0 ~ 1.0 사이 실수 |

> 💡 **핵심:** 컴퓨터는 '가짜 난수(의사 난수)'를 만들어 진짜 주사위처럼 사용합니다. 이걸로 우주 방사선 입자가 칩을 때리는 사건도 흉내 낼 수 있습니다!

### 1-2. 중2 확률: 경우의 수와 상대도수
중학교 2학년 때 배우는 **확률의 정의**는 다음과 같습니다.

$$\text{확률} = \frac{\text{사건이 일어나는 경우의 수}}{\text{모든 경우의 수}}$$

| 상황 | 확률 |
|------|------|
| 주사위에서 1이 나올 확률 | $\frac{1}{6} \approx 16.7\%$ |
| 동전에서 앞면이 나올 확률 | $\frac{1}{2} = 50\%$ |
| 로또 1등 당첨 확률 | $\frac{1}{8{,}145{,}060} \approx 0.00001\%$ |

**상대도수**는 많은 횟수로 시험했을 때 실제로 일어난 비율입니다. 시험 횟수가 많을수록 **이론 확률에 가까워집니다** (큰 수의 법칙).

### 1-3. 1% 확률 만들기 아이디어
컴퓨터의 `random()` 함수는 **0.0 ~ 1.0 사이의 실수**를 무작위로 뽑습니다.

> 💡 **아이디어:** 뽑은 숫자가 **0.01 보다 작으면 당첨!** 이라고 정하면, 당첨될 확률이 정확히 **1%** 입니다.

| 뽑힌 난수 | 0.01 미만? | 결과 |
|-----------|------------|------|
| 0.003 | ✅ | 당첨 (1%) |
| 0.52 | ❌ | 꽝 |
| 0.009 | ✅ | 당첨 (1%) |
| 0.99 | ❌ | 꽝 |

이 방법을 **확률 실험(probabilistic experiment)** 이라고 합니다.

### 1-4. 부동소수점(float) 숫자의 비트 구조 — 1주차에서 한 단계 더!

1주차에서는 **정수**가 비트로 어떻게 저장되는지 배웠습니다. 그런데 AI가 다루는 가중치는 **소수**(예: 0.5, -1.234, 0.0078)입니다. 소수는 어떻게 비트로 저장될까요?

컴퓨터는 **IEEE 754** 라는 약속을 써서 소수를 32비트로 저장합니다. 이걸 `float32` 라고 부릅니다.

$$\boxed{\;\underbrace{\mathrm{S}}_{1\text{비트}}\;\;\underbrace{\mathrm{EEEEEEEE}}_{8\text{비트}}\;\;\underbrace{\mathrm{MMMMMMMMMMMMMMMMMMMMMMM}}_{23\text{비트}}\;}$$

| 영역 | 길이 | 의미 | 비유 |
|------|------|------|------|
| **S (부호)** | 1 비트 | 0이면 양수, 1이면 음수 | "+ / −" 표지판 |
| **E (지수)** | 8 비트 | 값의 **크기 규모**($2^N$ 의 N) | "이 수가 1의 자리냐, 100의 자리냐, 0.001의 자리냐" |
| **M (가수)** | 23 비트 | 같은 규모 안에서의 **세부값** | "1.000과 1.999 사이에서 어디?" |

> 💡 **핵심:** 부호 1장 + 지수 8장 + 가수 23장. 총 32장의 비트 카드가 모여 하나의 소수를 표현합니다.

### 1-5. 어느 비트가 뒤집히느냐에 따라 피해가 달라진다!

1주차에서 "높은 자릿수의 비트가 뒤집히면 피해가 크다"는 걸 배웠죠. 부동소수점에서는 이게 **훨씬 더 극적**으로 일어납니다.

**숫자 1.0이 비트플립 방사선을 맞으면? (예시)**

| 뒤집힌 비트 영역 | 결과 | 피해 정도 |
|---|---|---|
| 부호(S) | 1.0 → **−1.0** | 부호만 반전 |
| **지수(E) 최상위** | 1.0 → **∞ (무한대!)** | 💀 가장 치명적 |
| 지수(E) 하위 | 1.0 → **0.5, 0.25, 0.0625, ...** | 크게 변함 |
| 가수(M) 상위 | 1.0 → **1.5, 1.25** | 어느 정도 변함 |
| 가수(M) 하위 | 1.0 → **1.0000001** | 거의 무시할 수준 |

> ⚠️ **충격적인 사실:** 같은 1% 확률로 비트가 뒤집혀도, **어느 비트가 맞느냐**에 따라 가중치가 ∞로 폭발하기도 하고 거의 변화가 없기도 합니다!

### 1-6. 우주 방사선 시뮬레이터의 진짜 원리

| 무엇 | 시뮬레이션에서 |
|------|----------------|
| 칩 속의 숫자 10,000개 | `float32` 배열 길이 10,000 |
| 방사선 입자가 무작위로 때림 | `np.random.rand(10000)` |
| 1% 확률로 명중 | `난수 < 0.01` |
| **명중한 숫자의 한 비트가 뒤집힘** | **`bits[i] ^= (1 << 무작위_위치)`** |

> 💡 **1주차 복습:** XOR (`^`)은 같은 자리를 만나면 0, 다르면 1 → 한 비트만 정확히 뒤집는 마법의 연산.

> 🔮 **앞으로 미리보기:** 9~15주차에서는 이 복잡한 비트플립 효과를 **"가우시안 노이즈"** 라는 한 가지 수식으로 단순화해서 다룹니다. 오늘 본 "지수 비트가 뒤집히면 값이 폭발한다"는 사실이 그 단순화의 정체예요.

### 실습 4-4: float32 카드 32장 들여다보기
```python
# 🟢 [실습 4-4] 소수가 비트로 어떻게 저장돼 있을까?
import numpy as np

def show_bits(x):
    """float32 숫자 x의 비트 표현을 S | E | M 으로 분리해서 보여주기."""
    arr = np.array([x], dtype=np.float32)
    bits = arr.view(np.uint32)[0]            # 같은 메모리를 정수로 보기
    bit_str = format(int(bits), '032b')      # 32자리 이진수 문자열
    sign = bit_str[0]
    exp  = bit_str[1:9]
    mant = bit_str[9:]
    return f"{x:>10.4f}  →  S={sign}  E={exp}  M={mant}"

print("값        →  부호  지수(8비트)   가수(23비트)")
print("-" * 65)
for x in [1.0, 2.0, 4.0, 0.5, 0.25, -1.0, 0.1, 100.0]:
    print(show_bits(x))
```

### 실습 4-5: 1.0의 비트를 하나씩 뒤집어 보자!
```python
# 🟢 [실습 4-5] 1.0의 32비트를 한 비트씩 뒤집으면 어떻게 변할까?
import numpy as np

def flip_bit(x, pos):
    """float32 숫자 x의 pos번째 비트를 뒤집은 결과를 반환."""
    arr = np.array([x], dtype=np.float32).copy()
    bits = arr.view(np.uint32)
    mask = np.uint32(1) << np.uint32(pos)
    bits[0] ^= mask
    return arr[0]

print(f"{'비트':>4} | {'영역':<6} | {'1.0 뒤집힌 후 값':>22}")
print("-" * 45)
for pos in range(31, -1, -1):
    if pos == 31:
        region = "S(부호)"
    elif 23 <= pos <= 30:
        region = "E(지수)"
    else:
        region = "M(가수)"
    result = flip_bit(1.0, pos)
    print(f"{pos:>4} | {region:<6} | {result!s:>22}")
```

> ⚠️ 30번 비트(지수 최상위)를 뒤집으면 `inf` 가 출력됩니다. 부호 1비트 + 지수 8비트 영역에 맞으면 피해가 어마어마하다는 걸 직접 확인하세요!

### 실습 4-6: 10,000개 숫자에 진짜 비트플립 방사선!
```python
# 🟢 [실습 4-6] 1주차의 비트플립을, 부동소수점 10,000개에서!
import numpy as np
np.random.seed(2026)

N = 10000        # 데이터 개수
P = 0.01         # 방사선 확률 (1%)

# 1) 깨끗한 데이터 (모두 1.0)
data = np.ones(N, dtype=np.float32)
bits = data.view(np.uint32)        # 같은 메모리를 정수로 보기

# 2) 어느 위치를 맞을지 결정 (1% 주사위)
hit_mask = np.random.rand(N) < P
hit_indices = np.where(hit_mask)[0]
n_hit = len(hit_indices)

# 3) 각 명중 위치에서 어느 비트(0~31)를 뒤집을지 무작위 선택
bit_positions = np.random.randint(0, 32, size=n_hit)

# 4) XOR로 한 비트씩 뒤집기
for i, pos in zip(hit_indices, bit_positions):
    bits[i] ^= (np.uint32(1) << np.uint32(pos))

# 5) 결과 분석
print(f"맞은 개수:           {n_hit}개  (이론 기대값: {int(N*P)}개)")
print(f"  → 정상값(1.0) 유지: {(data == 1.0).sum()}개")
print(f"  → 부호 바뀜 (음수): {(data < 0).sum()}개")
print(f"  → 무한대 (∞):       {np.isinf(data).sum()}개")
print(f"  → NaN:              {np.isnan(data).sum()}개")
finite_data = data[np.isfinite(data)]
print(f"\n유한한 값들의 통계:")
print(f"  평균: {finite_data.mean():.4f}  (원래는 1.0)")
print(f"  최대: {finite_data.max():.4f}")
print(f"  최소: {finite_data.min():.4f}")
```

### 실습 4-8: 🗣️ 수업 중 토론 — 변수 바꿔가며 실험하기

이 셀은 **수업 시간에 학생들이 직접 숫자를 바꿔가며** 결과를 비교해보는 토론용입니다. 아래 ⚙️ 표시된 부분만 바꿔서 여러 번 실행해 보세요.

```python
# 🟢 [실습 4-8] 토론용: 파라미터를 바꿔서 다시 실험!
import numpy as np

# ====== ⚙️ 여기 숫자만 바꿔보세요! ======
N = 10000                            # 데이터 개수
P = 0.01                             # 방사선 확률
ALLOWED_BITS = list(range(0, 32))    # 어떤 비트가 뒤집힐 수 있게 할까?
                                     # ▸ list(range(0, 23))  → 가수만 (M)
                                     # ▸ list(range(23, 31)) → 지수만 (E)
                                     # ▸ [31]                → 부호만 (옛날 모델!)
                                     # ▸ list(range(0, 32))  → 전부 (진짜)
SEED = 2026
# ============================================

np.random.seed(SEED)
data = np.ones(N, dtype=np.float32)
bits = data.view(np.uint32)

hit_mask = np.random.rand(N) < P
hit_indices = np.where(hit_mask)[0]
bit_positions = np.random.choice(ALLOWED_BITS, size=len(hit_indices))

for i, pos in zip(hit_indices, bit_positions):
    bits[i] ^= (np.uint32(1) << np.uint32(int(pos)))

print(f"파라미터: N={N}, P={P*100:.2f}%, 허용 비트 개수={len(ALLOWED_BITS)}개")
print(f"맞은 개수:        {len(hit_indices)}")
print(f"  → 정상값 유지: {(data == 1.0).sum()}")
print(f"  → 부호 바뀜:   {(data < 0).sum()}")
print(f"  → ∞ 또는 NaN:  {(~np.isfinite(data)).sum()}")
finite = data[np.isfinite(data)]
print(f"  → 유한값 평균: {finite.mean():.6f}  (원래 1.0)")
print(f"  → 유한값 최대: {finite.max()}")
print(f"  → 유한값 최소: {finite.min()}")
```

> 🗣️ **수업 중 토론 거리:**
> 1. `ALLOWED_BITS = [31]` 로 하면 결과가 어떻게 보이나요? 정상값 유지 + 부호 바뀜 둘만 보일 거예요. **이게 옛날 4주차의 "부호 반전 모델" 입니다!**
> 2. `ALLOWED_BITS = list(range(0, 23))` (가수만) 로 하면 평균은 어떻게 되나요? ∞은 몇 개 나오나요?

```python
import numpy as np
np.random.seed(2026)

def 비트플립_실험(허용비트, N=10000, P=0.01):
    data = np.ones(N, dtype=np.float32)
    bits = data.view(np.uint32)
    hit = np.where(np.random.rand(N) < P)[0]
    pos = np.random.choice(허용비트, size=len(hit))
    for i, p in zip(hit, pos):
        bits[i] ^= (np.uint32(1) << np.uint32(int(p)))
    유한 = data[np.isfinite(data)]
    return 유한.mean(), (~np.isfinite(data)).sum()
```

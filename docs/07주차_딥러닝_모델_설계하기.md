## 📖 1. 이론 설명

### 1-1. PyTorch는 "수학 계산기 도구상자"
지난 시간까지는 $y = wx + b$ 하나짜리 함수를 다뤘죠. 이제 이걸 **여러 개** 쌓고 싶습니다. 손으로 식을 쓰면 너무 길어지니, **PyTorch**가 준비해둔 **레고 블록**을 씁니다.

> 💡 **핵심:** PyTorch는 어려운 수학을 대신 해주는 도구. 우리는 **설계도**만 그리면 된다!

### 1-2. 레고 블록 3총사

#### 블록 1: `nn.Linear(입력 개수, 출력 개수)` — 곱셈판
일차함수 $y = wx + b$를 여러 개 묶은 것. 입력 숫자가 여러 개 들어오면, 여러 개의 출력을 한꺼번에 만들어줍니다.

```python
layer = nn.Linear(3, 2)   # 입력 3개 → 출력 2개
```

이 블록 안에는 "곱셈표($w$)"와 "덧셈수($b$)"가 들어있고, 학습 중에 PyTorch가 이 값을 계속 조정합니다.

#### 블록 2: `nn.ReLU()` — 꺾는 함수
일차함수만 계속 쌓으면 결국 또 일차함수입니다 (수학 법칙!). **곡선**을 만들려면 중간에 "꺾기"를 넣어야 합니다.

$$\text{ReLU}(x) = \max(0, x) = \begin{cases} x & (x \geq 0) \\ 0 & (x < 0) \end{cases}$$

음수는 0으로, 양수는 그대로. 아주 간단한 꺾기지만 이것만으로도 AI가 복잡한 곡선을 배울 수 있습니다!

| 입력 $x$ | -3 | -1 | 0 | 1 | 3 | 5 |
|----------|----|----|----|----|----|----|
| ReLU($x$) | 0 | 0 | 0 | 1 | 3 | 5 |

#### 블록 3: `nn.Sequential(...)` — 레고 조립판
블록들을 **순서대로** 연결하는 판입니다. 입력이 위에서 아래로 흘러갑니다.

```python
model = nn.Sequential(
    nn.Linear(3, 5),   # 1층: 3개 → 5개
    nn.ReLU(),         # 꺾기
    nn.Linear(5, 1),   # 2층: 5개 → 1개
)
```

### 1-3. 신경망 구조: 입력층 → 은닉층 → 출력층

```
   [입력층]       [은닉층]       [출력층]
     x₁  ───┐
     x₂  ───┼── Linear → ReLU ── Linear ── y
     x₃  ───┘
    (3개)         (5개)          (1개)
```

- **입력층(Input)**: 데이터가 들어오는 문
- **은닉층(Hidden)**: 중간에서 숨어 일하는 층 (여러 개 가능!)
- **출력층(Output)**: 최종 답이 나오는 곳

**층이 많을수록 "깊다(deep)" → Deep Learning!** 😎

### 1-4. 학습 루프의 4단계 (모든 AI가 이 루틴을 돈다)
지난 시간 경사하강법을 구조화한 것입니다.

| 단계 | 이름 | 하는 일 | 코드 |
|------|------|---------|------|
| 1 | **Forward (예측)** | 모델에 $x$ 넣고 예측값 $\hat{y}$ 얻기 | `y_pred = model(x)` |
| 2 | **Loss (오차 측정)** | 예측값과 정답의 차이 계산 | `loss = loss_fn(y_pred, y)` |
| 3 | **Backward (미분)** | 모든 $w, b$의 기울기 계산 | `loss.backward()` |
| 4 | **Step (업데이트)** | 기울기 방향으로 한 걸음 이동 | `optimizer.step()` |

이 4단계를 **수백, 수천 번 반복**하면 AI가 학습됩니다!

### 1-5. 옵티마이저(Optimizer) = 자동 산 내려가기 로봇
지난주엔 손으로 `w -= lr * w.grad`를 썼지만, PyTorch엔 이걸 자동으로 해주는 **옵티마이저**가 있습니다.

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

`SGD`는 Stochastic Gradient Descent(확률적 경사하강법)의 약자. 우리가 배운 그 "산 내려가기"의 진화 버전!

> 💡 **핵심:** 설계도 → 손실함수 → 옵티마이저 → 반복. 이 4가지가 AI 학습의 전부!

### 실습 2-2: Sequential로 신경망 조립하기
```python
# 🟢 [실습 2-2] 1 → 8 → 8 → 1 구조 신경망 만들기
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(1, 8),    # 입력층 → 은닉층1 (1개 → 8개)
    nn.ReLU(),          # 꺾기
    nn.Linear(8, 8),    # 은닉층1 → 은닉층2 (8개 → 8개)
    nn.ReLU(),          # 꺾기
    nn.Linear(8, 1),    # 은닉층2 → 출력층 (8개 → 1개)
)

print("완성된 신경망 설계도:")
print(model)
print()

# 파라미터(w, b) 개수 세기
total = sum(p.numel() for p in model.parameters())
print(f"이 신경망이 학습할 숫자 개수: {total}개")
```

### 실습 2-3: 손실함수와 옵티마이저 붙이기
```python
# 🟢 [실습 2-3] 학습에 필요한 3가지 - 모델, 손실함수, 옵티마이저
import torch
import torch.nn as nn

# 1. 모델 (설계도)
model = nn.Sequential(
    nn.Linear(1, 8),
    nn.ReLU(),
    nn.Linear(8, 1),
)

# 2. 손실함수 (오차를 어떻게 잴까?)
loss_fn = nn.MSELoss()   # 평균제곱오차: 지난주에 배운 그것!

# 3. 옵티마이저 (산 내려가기 로봇)
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

print("준비 완료!")
print(f"  손실함수: {loss_fn}")
print(f"  옵티마이저: {optimizer}")
```

### 실습 2-4: $y = 2x + 3$을 학습시키기 (완결 버전)
```python
# 🟢 [실습 2-4] 진짜 학습! y = 2x + 3 을 모델이 스스로 배우게 하기
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

# 데이터 만들기 (정답은 y = 2x + 3)
torch.manual_seed(42)
x_data = torch.linspace(-5, 5, 50).unsqueeze(1)        # shape: (50, 1)
y_data = 2 * x_data + 3 + torch.randn_like(x_data)*0.5  # 약간 노이즈 추가

# 모델, 손실함수, 옵티마이저
model = nn.Sequential(
    nn.Linear(1, 16),
    nn.ReLU(),
    nn.Linear(16, 1),
)
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# 학습 루프!
loss_history = []
for epoch in range(500):
    # 1. Forward (예측)
    y_pred = model(x_data)
    
    # 2. Loss (오차 측정)
    loss = loss_fn(y_pred, y_data)
    
    # 3. Backward (미분)
    optimizer.zero_grad()   # 이전 기울기 지우기
    loss.backward()
    
    # 4. Step (업데이트)
    optimizer.step()
    
    loss_history.append(loss.item())
    if (epoch+1) % 100 == 0:
        print(f"  epoch {epoch+1:>3}: loss = {loss.item():.4f}")

# 결과 그림 그리기
with torch.no_grad():
    y_pred_final = model(x_data)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))

ax1.scatter(x_data, y_data, label='data', alpha=0.6)
ax1.plot(x_data, y_pred_final, 'r-', linewidth=2, label='AI prediction')
ax1.set_title('AI learned y = 2x + 3')
ax1.legend(); ax1.grid(True, alpha=0.3)

ax2.plot(loss_history)
ax2.set_title('Loss decreasing over time')
ax2.set_xlabel('epoch'); ax2.set_ylabel('loss')
ax2.grid(True, alpha=0.3)

plt.tight_layout(); plt.show()
print("🎉 AI가 일차함수를 배워냈다!")
```

### 실습 2-5: 곡선도 배울 수 있을까? (ReLU의 힘)
```python
# 🟢 [실습 2-5] 신경망은 일차함수만 배우는 게 아니다! 곡선도 가능!
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

torch.manual_seed(0)

# 곡선 데이터: y = sin(x)
x_data = torch.linspace(-3, 3, 100).unsqueeze(1)
y_data = torch.sin(x_data) + torch.randn_like(x_data) * 0.1

# 더 깊은 모델
model = nn.Sequential(
    nn.Linear(1, 32),
    nn.ReLU(),
    nn.Linear(32, 32),
    nn.ReLU(),
    nn.Linear(32, 1),
)

optimizer = torch.optim.Adam(model.parameters(), lr=0.01)  # Adam: 더 똑똑한 옵티마이저
loss_fn = nn.MSELoss()

for epoch in range(2000):
    y_pred = model(x_data)
    loss = loss_fn(y_pred, y_data)
    optimizer.zero_grad(); loss.backward(); optimizer.step()
    if (epoch+1) % 500 == 0:
        print(f"  epoch {epoch+1}: loss = {loss.item():.4f}")

with torch.no_grad():
    y_pred = model(x_data)

plt.figure(figsize=(9, 5))
plt.scatter(x_data, y_data, alpha=0.4, label='data')
plt.plot(x_data, y_pred, 'r-', linewidth=2, label='AI prediction')
plt.title('Neural Network Can Learn Curves Too!')
plt.legend(); plt.grid(True, alpha=0.3); plt.show()
```

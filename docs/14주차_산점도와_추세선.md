## 📖 1. 이론 설명

### 1-1. 산점도(Scatter Plot): 중2 수학의 귀환
중학교 2학년 수학 통계 단원에서 배운 **산점도**, 기억나나요? 두 변수의 관계를 점으로 찍어 나타낸 그래프입니다.

| 이름 | 뜻 | 예시 |
|------|-----|------|
| X축 | 원인(독립변수) | 방사선 확률(%) |
| Y축 | 결과(종속변수) | AI 정확도(%) |
| 점 하나 | 실험 결과 한 쌍 | (5%, 80점) |

> 💡 **핵심:** 점이 "왼쪽 위 → 오른쪽 아래"로 흘러가면 **음의 상관관계**, 반대로 흐르면 **양의 상관관계**입니다.

### 1-2. 세 가지 관계 유형
실험 결과가 어떤 모양일 수 있을까요?

| 유형 | 모양 | 해석 |
|------|------|------|
| **정비례(양의 상관)** | 점이 $y = ax$ 처럼 올라감 ($a>0$) | X 커지면 Y도 커진다 |
| **반비례(음의 상관)** | 점이 오른쪽 아래로 내려감 | X 커지면 Y 작아진다 |
| **절벽형(비선형)** | 어느 점까지는 평평하다가 갑자기 뚝! | 임계점 전까지는 괜찮음 |

우리의 방사선 실험은 **어떤 유형**일까요? 직접 그려서 확인합니다!

### 1-3. 추세선(Trend Line)
점들이 흩어져 있을 때, **전체 흐름을 보여주는 한 줄**이 바로 추세선입니다.
- 꺾은선(간단): 점을 순서대로 이어주기
- 회귀선(고급): 모든 점에서 가장 가까운 직선 $y = ax + b$

일차함수 $y = ax + b$의 기울기 $a$가 **음수**면 반비례! $a$의 절댓값이 클수록 **급경사**입니다.

### 1-4. 임계점(Threshold): 절벽이 시작되는 곳
**임계점**이란 "여기를 넘으면 상황이 급변하는 지점"입니다.

$$\text{기울기 변화량} = \frac{\Delta Y}{\Delta X}$$

두 점 사이의 기울기를 계산해서, **갑자기 기울기가 커지는 구간**을 찾으면 그게 임계점입니다!

| 구간 | $\Delta X$ | $\Delta Y$ | 기울기 | 해석 |
|------|:---:|:---:|:---:|------|
| 0→1% | 1 | -3 | -3 | 완만 |
| 1→5% | 4 | -15 | -3.75 | 완만 |
| 5→10% | 5 | -38 | **-7.6** | 절벽! |
| 10→20% | 10 | -28 | -2.8 | 이미 붕괴 |

> 💡 **핵심:** 기울기가 가장 가팔라지는 구간이 **임계점**입니다.

### 1-5. 상관계수 살짝 맛보기
두 변수의 관계 강도를 숫자 하나로 나타내는 것이 **상관계수 $r$** 입니다.
- $r = +1$ : 완벽한 정비례
- $r = 0$ : 관계 없음
- $r = -1$ : 완벽한 반비례
- $|r|$ 이 0.7 이상이면 "강한 상관관계"

## 💻 2. 실습: 산점도와 추세선

### 실습 2-1: 실험 데이터 불러오기
```python
# 🟢 [실습 2-1] 13주차 실험 결과 준비

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# Colab에서 한글 깨짐 방지
plt.rcParams['axes.unicode_minus'] = False
# (한글 폰트가 필요하면 영어로 라벨 쓰는 걸 추천합니다)

# 13주차에 저장한 요약 데이터 (직접 입력 버전)
prob = np.array([0, 1, 5, 10, 20])              # 방사선 확률 (%)
acc_mean = np.array([97.67, 95.00, 80.00, 41.67, 12.33])  # 평균 정확도
acc_std  = np.array([0.58, 1.00, 2.00, 3.50, 2.50])       # 표준편차

df = pd.DataFrame({
    "prob": prob,
    "accuracy": acc_mean,
    "std": acc_std,
})
print(df)
```

### 실습 2-2: 기본 산점도 그리기
```python
# 🟢 [실습 2-2] 빨간 점으로 산점도 찍기

plt.figure(figsize=(9, 5))
plt.scatter(df["prob"], df["accuracy"], 
            color='red', s=120, zorder=3, label='Experiment')

plt.title('Radiation Probability vs AI Accuracy')
plt.xlabel('Radiation Probability (%)')
plt.ylabel('AI Accuracy (%)')
plt.grid(True, alpha=0.4)
plt.ylim(0, 105)
plt.legend()
plt.show()
```

### 실습 2-3: 꺾은선 추세선 추가 + 오차막대
```python
# 🟢 [실습 2-3] 점을 잇고, 표준편차를 오차막대로

plt.figure(figsize=(9, 5))

# 오차막대(errorbar) = 점 + 표준편차 막대
plt.errorbar(df["prob"], df["accuracy"], yerr=df["std"],
             fmt='o', color='red', ecolor='gray',
             markersize=10, capsize=5, label='Mean ± Std')

# 꺾은선 추세선
plt.plot(df["prob"], df["accuracy"], 
         color='blue', linestyle='--', linewidth=2, label='Trend (line)')

plt.title('Radiation vs AI Accuracy (with error bars)')
plt.xlabel('Radiation Probability (%)')
plt.ylabel('AI Accuracy (%)')
plt.grid(True, alpha=0.4)
plt.ylim(0, 105)
plt.legend()
plt.show()
```

### 실습 2-4: 회귀선(직선 추세선) 그리기
```python
# 🟢 [실습 2-4] 가장 적합한 직선 y = ax + b 찾기

# np.polyfit: 주어진 점들에 가장 가까운 다항식 찾기 (차수 1 = 직선)
coeffs = np.polyfit(df["prob"], df["accuracy"], deg=1)
a, b = coeffs
print(f"회귀선: y = {a:.2f} x + {b:.2f}")

# 부드러운 x 값을 만들어 직선 긋기
x_line = np.linspace(0, 22, 100)
y_line = a * x_line + b

plt.figure(figsize=(9, 5))
plt.scatter(df["prob"], df["accuracy"], color='red', s=120, zorder=3, label='Data')
plt.plot(x_line, y_line, color='green', linewidth=2, 
         label=f'Regression: y = {a:.2f}x + {b:.2f}')
plt.title('Linear Regression Line')
plt.xlabel('Radiation Probability (%)')
plt.ylabel('AI Accuracy (%)')
plt.grid(True, alpha=0.4)
plt.ylim(0, 105)
plt.legend()
plt.show()
```

### 실습 2-5: 임계점(Threshold) 찾기
```python
# 🟢 [실습 2-5] 기울기가 가장 가팔라지는 구간 = 임계점!

slopes = []
for i in range(len(prob) - 1):
    dx = prob[i+1] - prob[i]
    dy = acc_mean[i+1] - acc_mean[i]
    slope = dy / dx
    slopes.append(slope)
    print(f"  구간 {prob[i]}% → {prob[i+1]}%: 기울기 = {slope:.2f}")

# 가장 급한 기울기(절댓값 최대) 찾기
idx = np.argmax(np.abs(slopes))
print(f"\n⚠️ 임계점 구간: {prob[idx]}% ~ {prob[idx+1]}%")
print(f"   이 구간에서 정확도가 가장 빠르게 추락합니다!")

# 상관계수 계산 (중학교에서는 '살짝만')
r = np.corrcoef(prob, acc_mean)[0, 1]
print(f"\n📊 상관계수 r = {r:.3f}")
print(f"   → |r|이 1에 가까우니 매우 강한 {'음의' if r<0 else '양의'} 상관관계!")
```

### 실습 2-6: 최종 종합 그래프
```python
# 🟢 [실습 2-6] 포스터용 멋진 그래프 만들기

plt.figure(figsize=(10, 6))

# 1) 산점도
plt.scatter(df["prob"], df["accuracy"], color='red', s=150, zorder=5, label='Experiment')

# 2) 꺾은선
plt.plot(df["prob"], df["accuracy"], color='blue', linestyle='--', alpha=0.6, label='Trend')

# 3) 회귀선
plt.plot(x_line, y_line, color='green', alpha=0.5, label=f'Linear fit')

# 4) 임계점 표시
plt.axvspan(prob[idx], prob[idx+1], color='yellow', alpha=0.2, label='Threshold zone')

plt.title('Cosmic Radiation vs AI Accuracy (Full Analysis)', fontsize=14)
plt.xlabel('Radiation Probability (%)', fontsize=12)
plt.ylabel('AI Accuracy (%)', fontsize=12)
plt.grid(True, alpha=0.4)
plt.ylim(0, 105)
plt.legend(loc='upper right')
plt.tight_layout()
plt.savefig('14주차_산점도.png', dpi=150)  # 포스터용 고해상도 저장
plt.show()
```

**수업 목표:** AI가 공부(Training)하고 있는 도중에 **진짜 비트플립** 방사선을 맞히면 학습이 얼마나 엉망이 되는지 직접 관찰한다. 방어가 없으면 모델이 즉사하고, 가장 단순한 클리핑 방어만 있어도 학습이 살아남는다는 것을 epoch vs accuracy 그래프로 확인한다.

## 📖 1. 이론 설명

### 1-1. AI의 두 가지 상태: Training vs Inference

AI에게는 두 개의 인생 단계가 있습니다.

| 단계 | 모드 | 하는 일 | 비유 |
|------|------|---------|------|
| **Training** | `model.train()` | 문제집 풀며 공부 중 | 학생이 수학 문제 푸는 중 |
| **Inference** | `model.eval()` | 다 배우고 시험 보는 중 | 수능 시험장 |

이번 주차는 **Training 중에** 진짜 비트플립 방사선이 쏟아지는 상황을 시뮬레이션합니다.

### 1-2. Training 중 비트플립이 위험한 두 가지 이유

**(이유 1) 가중치 업데이트 방향이 왜곡됨**

AI가 학습할 때는 **가중치를 조금씩 고쳐가며** 정답에 가까워집니다. (6주차 경사하강법 복습)

$$W_{\text{새}} = W_{\text{예전}} - \eta \cdot \frac{\partial L}{\partial W} \;+\; \underbrace{\text{비트플립}}_{\text{방사선!}}$$

비트플립 한 번이 가중치 한 칸을 엉뚱한 곳으로 옮겨놓으면, 다음 epoch는 그 자리에서 다시 학습을 시작해야 합니다.

**(이유 2) ∞/NaN이 한 번 나오면 모델 전체가 죽는다**

9주차에서 봤듯, 비트플립이 지수(E) 최상위 비트에 맞으면 가중치 한 칸이 **±∞**이 됩니다. ∞이 들어간 행렬곱은 다음 층 출력을 통째로 ∞/NaN으로 만들고, 그래디언트도 NaN이 되어 옵티마이저가 나머지 모든 가중치를 NaN으로 덮어씁니다.

> ⚠️ **즉사 시나리오:** 비트 한 번 잘못 뒤집힘 → 모델 전체 NaN → 학습 영원히 멈춤.

### 1-3. 방어 — `harden_weights()` 클리핑

실제 위성 컴퓨터는 ∞/NaN이 나오자마자 정상 범위로 끌어당기는 **클리핑(clipping) 방어**를 항상 켜두고 삽니다 (15주차에서 자세히). 이번 주에는 가장 단순한 형태:

$$\text{harden}(w) = \mathrm{clip}(\,\text{nan\_to\_num}(w),\; -C,\; +C\,)$$

NaN은 0으로, ∞은 ±C로, 너무 큰 값은 ±C로 잘라냄. 비트플립 자체를 막는 것은 아니지만, **모델이 살아남을 수는 있게** 해줍니다.

### 1-4. 실험 설계
7~8주차에서 만든 MNIST 분류 모델을 그대로 씁니다.

| 실험군 | 처치 | 예상 |
|--------|------|------|
| **A (대조군, 정상)** | 방사선 없음 | 정확도 점점 올라감 |
| **B (비트플립 + 방어)** | 매 epoch 끝에 비트플립 → harden | 정확도 오르다가 진동 / 약간 낮음 |
| **C (비트플립, 방어 없음)** | 매 epoch 끝에 비트플립만 | 즉시 NaN으로 폭발 (학생이 직접 확인!) |

> 🗣️ **수업 중 토론:** B와 C를 같이 돌려보면 "왜 진짜 우주에 가는 AI는 방어가 필수인가?"의 답이 그래프 한 장으로 나옵니다.

```python
# 🟢 [실습 2-1] 필요한 라이브러리 & 데이터 준비
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import numpy as np
import matplotlib.pyplot as plt

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f"사용 장치: {device}")

# MNIST 데이터 불러오기 (7~8주차와 동일)
transform = transforms.Compose([transforms.ToTensor(),
                                transforms.Normalize((0.1307,), (0.3081,))])
train_set = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_set  = datasets.MNIST('./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_set, batch_size=128, shuffle=True)
test_loader  = DataLoader(test_set,  batch_size=1000, shuffle=False)
print(f"학습 데이터: {len(train_set)}장 | 테스트: {len(test_set)}장")
```

### 실습 2-2: 9주차에서 만든 비트플립 함수 + 방어 함수
```python
# 🟢 [실습 2-2] 9주차의 apply_space_radiation 재활용 + harden_weights 방어
import numpy as np

def apply_space_radiation(weight, probability=0.01, allowed_bits=None,
                          return_mask=False):
    """9주차에서 완성한 진짜 비트플립 함수 (PyTorch float32 텐서용)."""
    if allowed_bits is None:
        allowed_bits = list(range(32))
    device = weight.device
    shape = weight.shape

    arr = weight.detach().cpu().contiguous().clone().numpy()
    flat = arr.reshape(-1)
    bits = flat.view(np.uint32)

    hit_mask_np = np.random.rand(flat.size) < probability
    hit_indices = np.where(hit_mask_np)[0]
    bit_positions = np.random.choice(allowed_bits, size=len(hit_indices))

    if len(hit_indices) > 0:
        xor_masks = (np.uint32(1) << bit_positions.astype(np.uint32))
        bits[hit_indices] ^= xor_masks

    new_weight = torch.from_numpy(arr.copy()).to(device)
    if return_mask:
        return new_weight, torch.from_numpy(hit_mask_np.reshape(shape)).to(device)
    return new_weight


def harden_weights(weight, clip=3.0):
    """방어: ∞ → ±clip, NaN → 0, |w|>clip은 ±clip으로 잘라냄."""
    safe = torch.nan_to_num(weight, nan=0.0, posinf=clip, neginf=-clip)
    return torch.clamp(safe, -clip, clip)
```

### 실습 2-3: MNIST 모델 + 평가 함수
```python
# 🟢 [실습 2-3] 7~8주차 모델 재사용
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
        self.relu = nn.ReLU()
    def forward(self, x):
        x = x.view(-1, 784)
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        return self.fc3(x)

def evaluate(model, loader):
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            out = model(x)
            # NaN/∞ 출력은 자동으로 오답 처리 (argmax가 NaN이면 비교 실패)
            if torch.isnan(out).any() or torch.isinf(out).any():
                out = torch.nan_to_num(out, nan=-1e9, posinf=-1e9, neginf=-1e9)
            pred = out.argmax(dim=1)
            correct += (pred == y).sum().item()
            total += y.size(0)
    return 100.0 * correct / total
```

### 실습 2-4: [A군] 정상 환경에서 학습하기 (대조군)
```python
# 🟢 [실습 2-4] 방사선 없는 평화로운 학습
torch.manual_seed(0)
model_A = SimpleNet().to(device)
opt_A = optim.SGD(model_A.parameters(), lr=0.01, momentum=0.9)
loss_fn = nn.CrossEntropyLoss()

acc_history_A = []
EPOCHS = 8

for epoch in range(1, EPOCHS + 1):
    model_A.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt_A.zero_grad()
        loss_fn(model_A(x), y).backward()
        opt_A.step()
    acc = evaluate(model_A, test_loader)
    acc_history_A.append(acc)
    print(f"[A군-정상] Epoch {epoch:>2}: 정확도 = {acc:.2f}%")
```

### 실습 2-5: [B군] 학습 중 비트플립 + 방어 클리핑 ☢️🛡️
```python
# 🟢 [실습 2-5] 매 epoch 끝에 비트플립 + harden 방어 적용
torch.manual_seed(0)
np.random.seed(0)
model_B = SimpleNet().to(device)
opt_B = optim.SGD(model_B.parameters(), lr=0.01, momentum=0.9)

acc_history_B = []
RADIATION_PROB = 0.001        # 0.1% — 진짜 비트플립은 1%면 너무 강해서 0.1%부터 시작
CLIP = 3.0                    # 방어 클리핑 한계

for epoch in range(1, EPOCHS + 1):
    model_B.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt_B.zero_grad()
        loss_fn(model_B(x), y).backward()
        opt_B.step()

    # ☢️ 매 epoch 끝에 비트플립 → 🛡️ harden
    with torch.no_grad():
        for param in model_B.parameters():
            if param.dim() >= 2:   # 가중치 텐서만 (편향 bias 제외)
                flipped = apply_space_radiation(param.data,
                                                probability=RADIATION_PROB)
                param.data = harden_weights(flipped, clip=CLIP)

    acc = evaluate(model_B, test_loader)
    acc_history_B.append(acc)
    print(f"[B군-방사선+방어] Epoch {epoch:>2}: 정확도 = {acc:.2f}% ☢️🛡️")
```

### 실습 2-6: [C군] 방어 빼버리면? — 즉사 관찰 ☢️💀
```python
# 🟢 [실습 2-6] 같은 비트플립인데 harden 없이 — 모델이 즉사할 가능성
torch.manual_seed(0)
np.random.seed(0)   # 같은 시드 → B군과 같은 위치에 비트플립
model_C = SimpleNet().to(device)
opt_C = optim.SGD(model_C.parameters(), lr=0.01, momentum=0.9)

acc_history_C = []

for epoch in range(1, EPOCHS + 1):
    model_C.train()
    crashed = False
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt_C.zero_grad()
        out = model_C(x)
        loss = loss_fn(out, y)
        if torch.isnan(loss) or torch.isinf(loss):
            crashed = True
            break    # NaN loss → 더 학습 못함
        loss.backward()
        opt_C.step()

    # ☢️ 비트플립만 — 방어 없음!
    with torch.no_grad():
        for param in model_C.parameters():
            if param.dim() >= 2:
                param.data = apply_space_radiation(param.data,
                                                   probability=RADIATION_PROB)

    acc = evaluate(model_C, test_loader)
    acc_history_C.append(acc)
    flag = "💀 NaN!" if crashed or acc < 15 else ""
    print(f"[C군-방사선만] Epoch {epoch:>2}: 정확도 = {acc:.2f}% ☢️ {flag}")
```

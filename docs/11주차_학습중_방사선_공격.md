## 📖 1. 이론 설명

### 1-1. AI의 두 가지 상태: Training vs Inference

AI에게는 두 개의 인생 단계가 있습니다.

| 단계 | 모드 | 하는 일 | 비유 |
|------|------|---------|------|
| **Training** | `model.train()` | 문제집 풀며 공부 중 | 학생이 수학 문제 푸는 중 |
| **Inference** | `model.eval()` | 다 배우고 시험 보는 중 | 수능 시험장 |

이번 주차는 **Training 중에** 방사선이 쏟아지는 상황을 시뮬레이션합니다.

### 1-2. Training 중 방사선이 위험한 이유

AI가 학습할 때는 **가중치를 조금씩 고쳐가며** 정답에 가까워집니다. 이 과정을 **경사하강법(Gradient Descent)** 이라고 하죠 (6주차 내용 복습!).

**정상 학습:**
$$W_{\text{새}} = W_{\text{예전}} - \eta \cdot \frac{\partial L}{\partial W}$$

여기서 $\eta$ 는 학습률, $\frac{\partial L}{\partial W}$ 는 오차의 기울기입니다.

**방사선 학습:**
$$W_{\text{새}} = W_{\text{예전}} - \eta \cdot \frac{\partial L}{\partial W} + \underbrace{\text{NOISE}}_{\text{방사선!}}$$

노이즈가 끼면 AI는 **목적지와 정반대 방향으로 걷기**도 합니다. 눈 가리고 계곡으로 내려가던 AI가 갑자기 산등성이로 밀려 올라가는 꼴이죠! 🏔️

> 💡 **핵심:** 학습 중 방사선은 단순한 오류가 아니라 **잘못된 방향으로 학습을 유도**하는 더 큰 재앙입니다!

### 1-3. 실험 설계
7~8주차에서 만든 MNIST 분류 모델을 그대로 씁니다.

| 실험군 | 처치 | 예상 |
|--------|------|------|
| A (대조군, 정상) | 방사선 없음 | 정확도 점점 올라감 |
| B (실험군, 방사선) | 매 epoch 끝날 때 `apply_space_radiation(p=0.01)` | 정확도 오르다가 꺾이거나 진동 |

> ⚠️ **관찰 포인트:** 그래프 모양이 정상은 완만한 곡선, 방사선군은 지그재그일 것!

## 💻 2. 실습

### 실습 2-1: 환경 준비 (Colab)
```python
# 🟢 [실습 2-1] 필요한 라이브러리 & 데이터 준비
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f"사용 장치: {device}")

# MNIST 데이터 불러오기 (7~8주차와 동일)
transform = transforms.Compose([transforms.ToTensor(),
                                transforms.Normalize((0.1307,), (0.3081,))])
train_set = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_set  = datasets.MNIST('./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_set, batch_size=128, shuffle=True)
test_loader  = DataLoader(test_set,  batch_size=1000, shuffle=False)
print(f"학습 데이터: {len(train_set)}장 | 테스트: {len(test_set)}장")
```

### 실습 2-2: 9주차에서 만든 방사선 함수 재활용
```python
# 🟢 [실습 2-2] apply_space_radiation (9주차 복습)
def apply_space_radiation(weight, probability=0.01, noise_scale=1.0):
    dice = torch.rand_like(weight)
    hit_mask = dice < probability
    noise = torch.randn_like(weight) * noise_scale
    return weight + hit_mask.float() * noise
```

### 실습 2-3: 간단한 MNIST 모델 정의
```python
# 🟢 [실습 2-3] 7~8주차 모델 재사용
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
        self.relu = nn.ReLU()

    def forward(self, x):
        x = x.view(-1, 784)          # 28×28 이미지 → 784 벡터로
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        return self.fc3(x)

print("모델 구조:")
print(SimpleNet())
```

### 실습 2-4: 테스트 정확도 측정 함수
```python
# 🟢 [실습 2-4] 시험 봐서 정확도 구하기
def evaluate(model, loader):
    model.eval()            # 시험 모드
    correct = 0
    total = 0
    with torch.no_grad():
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            pred = model(x).argmax(dim=1)
            correct += (pred == y).sum().item()
            total += y.size(0)
    return 100.0 * correct / total
```

### 실습 2-5: [A군] 정상 환경에서 학습하기 (대조군)
```python
# 🟢 [실습 2-5] 방사선 없는 평화로운 학습
torch.manual_seed(0)
model_A = SimpleNet().to(device)
opt_A = optim.SGD(model_A.parameters(), lr=0.01, momentum=0.9)
loss_fn = nn.CrossEntropyLoss()

acc_history_A = []
EPOCHS = 8

for epoch in range(1, EPOCHS + 1):
    model_A.train()           # 학습 모드!
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt_A.zero_grad()
        loss = loss_fn(model_A(x), y)
        loss.backward()
        opt_A.step()
    acc = evaluate(model_A, test_loader)
    acc_history_A.append(acc)
    print(f"[A군-정상] Epoch {epoch:>2}: 정확도 = {acc:.2f}%")
```

### 실습 2-6: [B군] 학습 중 방사선 공격! ☢️
```python
# 🟢 [실습 2-6] 매 epoch 끝날 때마다 가중치에 방사선 주입
torch.manual_seed(0)
model_B = SimpleNet().to(device)
opt_B = optim.SGD(model_B.parameters(), lr=0.01, momentum=0.9)

acc_history_B = []
RADIATION_PROB = 0.01    # 1% 확률
NOISE_SCALE = 0.3        # 가중치의 평균 크기를 고려해 적당히 설정

for epoch in range(1, EPOCHS + 1):
    model_B.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt_B.zero_grad()
        loss = loss_fn(model_B(x), y)
        loss.backward()
        opt_B.step()

    # ☢️ 매 epoch 끝에 방사선 주입!
    with torch.no_grad():
        for param in model_B.parameters():
            if param.dim() >= 2:   # 가중치 텐서만 (편향 bias는 제외)
                param.data = apply_space_radiation(param.data,
                                                    probability=RADIATION_PROB,
                                                    noise_scale=NOISE_SCALE)

    acc = evaluate(model_B, test_loader)
    acc_history_B.append(acc)
    print(f"[B군-방사선] Epoch {epoch:>2}: 정확도 = {acc:.2f}% ☢️")
```

### 실습 2-7: 결과 비교 그래프
```python
# 🟢 [실습 2-7] 두 집단 정확도 비교 (이게 핵심 결과물!)
epochs = list(range(1, EPOCHS + 1))

plt.figure(figsize=(10, 6))
plt.plot(epochs, acc_history_A, 'o-', color='green',
         label='A: Normal Training', linewidth=2, markersize=8)
plt.plot(epochs, acc_history_B, 'x--', color='red',
         label=f'B: Radiation ({RADIATION_PROB*100}%) during training',
         linewidth=2, markersize=10)

plt.title('Training with vs without Cosmic Radiation', fontsize=14)
plt.xlabel('Epoch')
plt.ylabel('Test Accuracy (%)')
plt.legend(fontsize=12)
plt.grid(True, alpha=0.3)
plt.ylim(0, 100)
plt.show()

# 💡 B군 곡선이 들쑥날쑥(진동)하면서 A군보다 낮게 머문다면 실험 성공!
```

### 실습 2-8: 결과 표로 정리
```python
# 🟢 [실습 2-8] 숫자로 결론 정리하기
print(f"{'Epoch':>6} | {'A (정상)':>10} | {'B (방사선)':>12} | {'차이':>8}")
print("-" * 50)
for i, (a, b) in enumerate(zip(acc_history_A, acc_history_B), start=1):
    diff = a - b
    print(f"{i:>6} | {a:>9.2f}% | {b:>11.2f}% | {diff:>+7.2f}")

print(f"\n최종 정확도 차이: {acc_history_A[-1] - acc_history_B[-1]:.2f}%p")
print("⚠️ 학습 중 방사선은 AI를 '헷갈리게' 만들어 수렴을 방해합니다.")
```

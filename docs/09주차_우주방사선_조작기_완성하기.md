## 📖 1. 이론 설명

### 1-1. 지금까지의 여정을 다시 정리해보자
- **1주차:** 정수의 비트가 뒤집히면 숫자가 어떻게 변하는지 (XOR 연산)
- **4주차:** `float32`(IEEE 754) 10,000개에 진짜 비트플립 — 부호(S), 지수(E), 가수(M) 영역별 피해가 천차만별
- **7~8주차:** PyTorch로 손글씨 숫자(MNIST)를 맞히는 인공지능 — 지금 **"평화로운 지구"** 상태
- **이번 주:** 7~8주차 AI에게 4주차의 비트플립을 그대로 적용 → **수만~수십만 개 가중치에 진짜 우주 방사선**

> 💡 **핵심:** 4주차에서 numpy 배열에 했던 일을, 9주차에서는 **PyTorch 텐서**에 그대로 합니다. 도구가 바뀔 뿐 메커니즘은 동일!

### 1-2. PyTorch 텐서(Tensor)란?
텐서는 **숫자가 줄줄이 묶여 있는 표**입니다. 3주차 Numpy 행렬과 거의 같지만, GPU 가속과 자동 미분이 가능하도록 업그레이드된 버전입니다.

| 이름 | 예시 | 차원 |
|------|------|------|
| 스칼라 | `5` | 0차원 |
| 벡터 | `[1, 2, 3]` | 1차원 |
| 행렬 | `[[1,2],[3,4]]` | 2차원 |
| 3차원 텐서 | 사진 묶음 | 3차원 이상 |

### 1-3. 텐서에 진짜 비트플립 — 4단계 설계

**① 모양이 똑같은 주사위 텐서 만들기**  
$$\text{dice} \sim \text{Uniform}(0, 1), \quad \text{shape} = \text{shape}(W)$$

**② 1% 확률로 명중 위치 결정 (마스크)**  
$$\text{hit}_{i,j} = (\text{dice}_{i,j} < p)$$

**③ 명중 위치마다 어느 비트(0~31)를 뒤집을지 무작위로 선택**

**④ 그 위치의 비트를 XOR로 한 개 뒤집기 (4주차와 동일한 연산)**  
$$\text{bits}[i] \;\mathrel{{\oplus}{=}}\; (1 \ll \text{pos})$$

> 💡 **핵심:** 9주차의 새로움은 "차원이 커진 것" 뿐. 비트플립 자체는 4주차에서 이미 다 배웠어요!

### 1-4. 비트플립이 텐서에서 만들어내는 4가지 운명

가중치 한 칸이 비트 하나에 맞으면 (4주차 1-5 복습):

| 맞은 비트 영역 | 결과 | 이게 인공지능에 미치는 영향 |
|---|---|---|
| **부호(S)** | 가중치 부호 반전 | 그 가중치의 영향 방향이 뒤집힘 |
| **지수(E) 최상위** | 가중치 → **±∞** | 💀 다음 층 forward pass 전체가 ∞ |
| 지수(E) 하위 | 값 × 2, × 4, × 8, ... | 가중치 폭발 → 그래디언트 폭발 |
| 가수(M) | 1.0001, 1.5 등 미세 변화 | 거의 무시 가능 |

> ⚠️ **충격적인 사실:** 가중치 단 **한 칸**이 ∞이 되어도, 행렬곱 한 번이면 그 층의 모든 출력이 ∞ 또는 NaN으로 변합니다. 비트 한 개가 모델 전체를 죽일 수 있어요!

### 1-5. 그래서 "방어"가 왜 필요한가
실제 위성 컴퓨터는 ∞/NaN이 발생하자마자 잡아내서 정상 범위로 끌어당기는 **에러 정정/클리핑** 시스템을 갖고 있습니다. 이런 방어가 없으면 비트 한 번 뒤집힘에 모델이 통째로 죽습니다. 11주차부터 이 문제가 본격적으로 터지고, 15주차에서 방어 전략을 모두 다룹니다.

```python
def show_tensor_bits(t):
    """float32 텐서 한 칸씩 32비트 표현 출력."""
    arr = t.detach().cpu().contiguous().clone().numpy()
    bits_view = arr.view(np.uint32)
    for x, b in zip(arr.flatten(), bits_view.flatten()):
        bit_str = format(int(b), '032b')
        print(f"  {x:>8.4f}  →  S={bit_str[0]}  E={bit_str[1:9]}  M={bit_str[9:]}")

w = torch.tensor([1.0, 2.0, 0.5, -1.0, 0.1], dtype=torch.float32)
```

### 실습 2-3: 텐서 한 칸의 비트 하나만 뒤집어 보기

```python
# 🟢 [실습 2-3] PyTorch 텐서에서도 1.0의 비트별 뒤집기를 재현 (4주차 4-5)

def flip_one_bit_in_tensor(weight, idx, pos):
    """weight를 평탄화한 뒤 idx번째 칸의 pos번째 비트를 뒤집은 새 텐서 반환."""
    arr = weight.detach().cpu().contiguous().clone().numpy()
    flat = arr.reshape(-1)
    bits = flat.view(np.uint32)
    bits[idx] ^= (np.uint32(1) << np.uint32(int(pos)))
    return torch.from_numpy(arr).to(weight.device)

base = torch.ones(1, dtype=torch.float32)
print(f"{'비트':>4} | {'영역':<8} | {'1.0 뒤집힌 후':>20}")
print("-" * 45)
for pos in [31, 30, 29, 23, 22, 0]:
    if pos == 31: region = "S(부호)"
    elif 23 <= pos <= 30: region = "E(지수)"
    else: region = "M(가수)"
    result = flip_one_bit_in_tensor(base, 0, pos)
    print(f"{pos:>4} | {region:<8} | {result.item()!s:>20}")
```

### 실습 2-4: `apply_space_radiation()` 함수 완성 (이번 주 핵심!)
```python
# 🟢 [실습 2-4] PyTorch 텐서용 진짜 비트플립 함수
import torch
import numpy as np

def apply_space_radiation(weight, probability=0.01, allowed_bits=None,
                          return_mask=False):
    """
    PyTorch float32 텐서에 한 비트씩 진짜로 뒤집기 (4주차 4-6의 텐서 버전).

    - weight: float32 텐서 (어떤 모양이든, CPU/GPU 상관없음)
    - probability: 각 가중치 칸이 비트플립을 당할 확률
    - allowed_bits: 뒤집힐 수 있는 비트 목록 (기본=0~31 전부)
    - return_mask: True면 (새 가중치, 명중 마스크) 둘 다 반환

    Returns:
        new_weight (Tensor)  또는  (new_weight, hit_mask)
    """
    if allowed_bits is None:
        allowed_bits = list(range(32))

    device = weight.device
    shape = weight.shape

    # numpy로 옮겨서 비트플립 (PyTorch에는 uint32 view가 없어서 numpy가 안전함)
    arr = weight.detach().cpu().contiguous().clone().numpy()
    assert arr.dtype == np.float32, "apply_space_radiation은 float32 텐서만 처리합니다."

    flat = arr.reshape(-1)
    bits = flat.view(np.uint32)            # 같은 메모리를 정수로 보기

    # 1) 어느 칸을 맞을지 (1% 주사위)
    hit_mask_np = np.random.rand(flat.size) < probability
    hit_indices = np.where(hit_mask_np)[0]

    # 2) 각 명중 위치에서 어느 비트(0~31)를 뒤집을지
    bit_positions = np.random.choice(allowed_bits, size=len(hit_indices))

    # 3) XOR 마스크를 한 번에 만들어서 일괄 뒤집기 (벡터화)
    if len(hit_indices) > 0:
        xor_masks = (np.uint32(1) << bit_positions.astype(np.uint32))
        bits[hit_indices] ^= xor_masks

    # 4) 텐서로 복원
    new_weight = torch.from_numpy(arr.copy()).to(device)
    if return_mask:
        hit_mask = torch.from_numpy(hit_mask_np.reshape(shape)).to(device)
        return new_weight, hit_mask
    return new_weight

# 작은 텐서로 테스트
torch.manual_seed(0)
np.random.seed(0)
W = torch.randn(10, 10, dtype=torch.float32) * 0.1

W_dmg, mask = apply_space_radiation(W, probability=0.05, return_mask=True)
print(f"명중 개수:        {mask.sum().item()}")
print(f"  → NaN 개수:     {torch.isnan(W_dmg).sum().item()}")
print(f"  → ∞ 개수:       {torch.isinf(W_dmg).sum().item()}")
print(f"  → 부호 바뀜:    {((W * W_dmg) < 0).sum().item()}")
finite = W_dmg[torch.isfinite(W_dmg)]
print(f"  → 유한값 평균:  {finite.mean().item():.4f} (원래 약 0)")
```

### 실습 2-8: 옛 가우시안 모델 vs 진짜 비트플립 — 차이 직접 확인
```python
# 🟢 [실습 2-8] 두 모델의 결과를 같은 조건에서 비교
import torch
import numpy as np

def apply_gaussian_radiation(weight, probability=0.01, noise_scale=1.0):
    """비교용 — 옛 9주차에서 쓰던 가우시안 노이즈 모델."""
    dice = torch.rand_like(weight)
    hit_mask = dice < probability
    noise = torch.randn_like(weight) * noise_scale
    return weight + hit_mask.float() * noise

torch.manual_seed(0)
W = torch.randn(100, 100, dtype=torch.float32) * 0.1

torch.manual_seed(0)
W_gauss = apply_gaussian_radiation(W, probability=0.01, noise_scale=1.0)

np.random.seed(0)
W_bitflip = apply_space_radiation(W, probability=0.01)

def stats(name, diff_tensor):
    finite = diff_tensor[torch.isfinite(diff_tensor)]
    n_bad = (~torch.isfinite(diff_tensor)).sum().item()
    return (f"{name:<22} | "
            f"NaN/∞: {n_bad:>4} | "
            f"|평균변화|: {finite.abs().mean().item():>7.4f} | "
            f"|최대변화|: {finite.abs().max().item():>10.4g}")

print(stats("가우시안 모델",     W_gauss   - W))
print(stats("진짜 비트플립",      W_bitflip - W))

print("\n💡 가우시안은 부드럽고 NaN/∞이 안 생깁니다 — 분석은 쉽지만 실제와 거리가 있어요.")
print("   진짜 비트플립은 가끔 ∞을 만들어내며 모델을 즉사시키기도 합니다.")
print("   이 차이가 11~15주차에서 왜 '방어 전략'이 필수인지 보여주는 핵심 동기예요!")
```
